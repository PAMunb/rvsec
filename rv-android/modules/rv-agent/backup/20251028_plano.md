## LangGraph Architecture (Simple)

### State Definition

```python
from langgraph.graph import MessagesState

class RVAgentState(MessagesState):
    """Extends MessagesState with Android-specific fields."""
    iteration_count: int = 0
    app_package: str = ""
    device_id: str = ""
```

### Graph Construction

```python
from langgraph.graph import START, StateGraph, END
from langgraph.prebuilt import tools_condition, ToolNode
from langgraph.checkpoint.sqlite import SqliteSaver

def create_graph():
    # Memory
    memory = SqliteSaver.from_conn_string("checkpoints.db")

    # Build builder
    builder = StateGraph(RVAgentState)
    builder.add_node("assistant", assistant_node)
    builder.add_node("tools", ToolNode(tools))  # Prebuilt!

    # Edges
    builder.add_edge(START, "assistant")
    builder.add_conditional_edges("assistant", tools_condition)  # Prebuilt!
    builder.add_edge("tools", "assistant")

    return builder.compile(checkpointer=memory)
```

**That's it!** No manual routing, no complex state management.

### Visual Flow

```
START → assistant → tools_condition
                    ├─ tools → assistant (loop)
                    └─ END
```

## Core Changes

### 1. Remove Simulation

**Files to modify**:
- `device_adapter.py` → `device_interface.py`
- `autonomous_tools.py` → `android_tools.py`
- `rv_agent.py` → `agent.py`

**Simple rule**: Remove all `else:` simulation branches, raise exceptions instead.

```python
# Before
if self.device_interface:
    self.device_interface.click(x, y)
else:
    print("Simulated click")  # ❌ Remove this

# After
if not self.device_interface:
    raise RuntimeError("Device interface required")
self.device_interface.click(x, y)
```

### 2. Emulator Validation

```python
def _is_emulator(device_id: str) -> bool:
    return device_id.startswith("emulator-") or \
           device_id.startswith("localhost:")

# In __init__
if not self._is_emulator(device_id):
    raise ValueError(f"Only emulators allowed: {device_id}")
```

### 3. Screenshot Optimizer

```python
class ScreenshotOptimizer:
    DEFAULT_TARGET_SIZE = (728, 1288)  # Multiples of 28!
    DEFAULT_QUALITY = 85

    def optimize(self, image_path: str) -> str:
        img = Image.open(image_path)

        # Convert RGBA → RGB
        if img.mode == 'RGBA':
            background = Image.new('RGB', img.size, (255, 255, 255))
            background.paste(img, mask=img.split()[3])
            img = background

        # Resize
        img.thumbnail(self.DEFAULT_TARGET_SIZE, Image.Resampling.LANCZOS)

        # Save as JPEG
        buffer = BytesIO()
        img.save(buffer, format="JPEG", quality=self.DEFAULT_QUALITY)

        return base64.b64encode(buffer.getvalue()).decode("utf-8")
```

## Testing (Minimal)

### Test 1: Tools Work

```python
# test_tools.py
from langchain_ollama import ChatOllama
from langchain_core.tools import tool

@tool
def test_click(x: int, y: int) -> str:
    """Test tool."""
    return f"Clicked at ({x}, {y})"

llm = ChatOllama(model="qwen-vision-tools-v1")
llm_with_tools = llm.bind_tools([test_click])

response = llm_with_tools.invoke([HumanMessage("Click at 100, 200")])
assert hasattr(response, 'tool_calls')
print("✅ Tools working")
```

### Test 2: Graph Works

```python
    "messages": [HumanMessage("Click at 100, 200")]
})

```
