# RV-Agent Refactoring Plan - 2025-10-28

## Overview

This document outlines the complete refactoring of the rv-agent module to implement a production-ready autonomous Android testing agent using LangGraph and LangChain with Ollama integration. The refactoring removes simulation code, enforces real device requirements, optimizes multimodal processing, and follows architectural standards established in the RV-Android framework.

## Objectives

1. **Remove simulation code**: Enforce real Android emulator usage without fallbacks
2. **Implement LangGraph architecture**: Use StateGraph with **prebuilt components** (tools_condition, ToolNode) following LangGraph course patterns
3. **Enable Ollama tool-calling**: Use custom Modelfile to enable function calling with vision models
4. **Optimize screenshot processing**: Use Qwen2.5-VL optimal resolution (multiple of 28) to reduce token cost
5. **Add memory persistence**: Use SqliteSaver checkpointer for session state persistence
6. **Add observability**: LangSmith tracing + dedicated observability nodes in graph
7. **Implement basic actions**: Provide click, input, scroll, back operations via real device interface
8. **Follow code standards**: Use established comment templates, remove bias terms, maintain current state documentation

### Qwen2.5-VL Model Specifications (Researched)

Based on official documentation and technical report:

**Resolution Requirements**:
- Minimum: 56×56 pixels (3,136 pixels)
- Maximum: 3584×3584 pixels (12,845,056 pixels)
- **Critical**: Dimensions must be multiples of 28
- Token calculation: `tokens = total_pixels / (28 × 28) = total_pixels / 784`

**Optimal Configuration** (recommended by Qwen team):
- min_pixels = 256 × 28 × 28 = 200,704 pixels
- max_pixels = 1280 × 28 × 28 = 1,003,520 pixels
- Result: 256-1280 tokens per image (optimal range)

**Our Configuration** (adjusted for multiples of 28):
- Target size: 728×1288 pixels (26×28 by 46×28)
- Total pixels: 937,664
- Expected tokens: ~937,664 / 784 = **~1,196 tokens**
- ✅ Within optimal range 256-1280
- ✅ Maintains 9:16 aspect ratio (smartphone standard)

**Key Features**:
- Dynamic resolution with aspect ratio preservation
- No coordinate normalization (uses real pixel values)
- Supports formats: local files, base64, URLs

### Architectural Decisions

1. **LangGraph with Prebuilt Components** (follows LangGraph course patterns):
   - Uses `tools_condition` for automatic routing (tool_calls → tools, no tool_calls → END)
   - Uses `ToolNode` prebuilt component for automatic tool execution
   - Extends `MessagesState` for clean state management
   - No manual routing logic - leverages LangGraph best practices

2. **Memory with SqliteSaver Checkpointer**:
   - Automatic state persistence at each graph step
   - Thread-based session management via `thread_id`
   - Resume capability from any checkpoint
   - Supports both in-memory (testing) and persistent (production) storage

3. **Observability Architecture**:
   - LangSmith automatic tracing for all graph executions
   - Dedicated observability nodes: `metrics`, `screenshot_tracker`
   - Real-time event streaming with `stream_mode="values"`
   - Comprehensive logging integration with rv-android-core

4. **Custom Ollama Model**: Enables tool-calling for vision models
   - Qwen2.5-VL base model with Llama 3.1 template adaptation
   - Adds `.Tools` template variable to signal function calling support
   - Maintains vision capabilities while enabling structured tool invocation

5. **Screenshot Optimization** (Qwen2.5-VL specific):
   - Resize to 728×1288 pixels (multiples of 28 requirement)
   - JPEG compression at 85% quality
   - RGBA to RGB conversion for smaller payload
   - ~1,196 tokens per image (within optimal 256-1280 range)
   - 50-70% size reduction vs original PNG

6. **Real Device Only**: No simulation fallbacks
   - Device interface requires emulator connection
   - Validation enforces emulator device ID format
   - Fail-fast error handling if device unavailable

7. **Component-Based Design**: Following rv-platform patterns
   - Dependency injection for device interface
   - Event-driven communication via EventBus
   - Performance monitoring integration
   - Comprehensive error handling

```python
"""
Test LangGraph integration with tool execution.

Validates that StateGraph + ToolNode work correctly with the custom
Ollama model for automated tool execution.
"""

from typing import TypedDict, List, Annotated
from langgraph.graph import StateGraph, END
from langgraph.prebuilt import ToolNode
from langchain_ollama import ChatOllama
from langchain_core.tools import tool
from langchain_core.messages import HumanMessage, BaseMessage


class TestState(TypedDict):
    """State structure for test builder."""
    messages: Annotated[List[BaseMessage], "messages"]


@tool
def android_click(coordinates: str, reasoning: str) -> str:
    """
    Click on Android UI element.

    Args:
        coordinates: Target coordinates in format "x,y"
        reasoning: Explanation of why this click is performed

    Returns:
        Confirmation message
    """
    return f"Mock clicked at {coordinates}: {reasoning}"


def test_langgraph_tool_execution():
    """Verify LangGraph executes tools automatically."""

    # Initialize LLM with tools
    llm = ChatOllama(
        model="qwen-vision-tools-v1",
        temperature=0.1,
        base_url="http://localhost:11434"
    )
    tools = [android_click]
    llm_with_tools = llm.bind_tools(tools)

    # Define agent node
    def agent_node(state: TestState) -> TestState:
        response = llm_with_tools.invoke(state["messages"])
        return {"messages": [response]}

    # Define router
    def router(state: TestState) -> str:
        last_message = state["messages"][-1]
        if hasattr(last_message, 'tool_calls') and last_message.tool_calls:
            return "tools"
        return "end"

    # Build builder
    graph = StateGraph(TestState)
    graph.add_node("agent", agent_node)
    graph.add_node("tools", ToolNode(tools))
    graph.set_entry_point("agent")
    graph.add_conditional_edges(
        "agent",
        router,
        {"tools": "tools", "end": END}
    )
    graph.add_edge("tools", "agent")

    app = graph.compile()

    # Execute test
    result = app.invoke({
        "messages": [HumanMessage(content="Click the submit button at 100,200")]
    })

    # Validate tool execution
    messages_str = " ".join([str(m.content) for m in result["messages"]])
    assert "Mock clicked" in messages_str, "Tool was not executed"

    print("✅ LangGraph + ToolNode executed successfully")
    return True


if __name__ == "__main__":
    test_langgraph_tool_execution()
```

```python
"""
Test screenshot optimization for vision models.

Validates that image optimization reduces size while maintaining
visual quality for UI element identification.
"""

import base64
from io import BytesIO
from pathlib import Path
from PIL import Image


def optimize_screenshot_for_vision(
    image_path: str,
    target_size: tuple = (720, 1280),
    quality: int = 85,
    format: str = "JPEG"
) -> str:
    """
    Optimize screenshot for vision model input.

    Args:
        image_path: Path to screenshot file
        target_size: Target (width, height) tuple
        quality: JPEG quality 1-100
        format: Output format (JPEG or PNG)

    Returns:
        Base64 encoded optimized image
    """
    # Load image
    img = Image.open(image_path)
    original_size = Path(image_path).stat().st_size

    # Convert RGBA to RGB for JPEG
    if img.mode == 'RGBA' and format == "JPEG":
        background = Image.new('RGB', img.size, (255, 255, 255))
        background.paste(img, mask=img.split()[3])
        img = background

    # Resize maintaining aspect ratio
    img.thumbnail(target_size, Image.Resampling.LANCZOS)

    # Encode to bytes
    buffer = BytesIO()
    img.save(buffer, format=format, quality=quality, optimize=True)
    encoded = base64.b64encode(buffer.getvalue()).decode("utf-8")

    # Calculate metrics
    optimized_size = len(encoded)
    reduction = (1 - optimized_size / original_size) * 100

    print(f"Original: {original_size:,} bytes")
    print(f"Optimized: {optimized_size:,} bytes")
    print(f"Reduction: {reduction:.1f}%")
    print(f"Dimensions: {img.size}")

    assert optimized_size < original_size, "No size reduction"
    assert reduction > 30, f"Insufficient reduction: {reduction:.1f}%"

    return encoded


def test_screenshot_optimization():
    """Verify screenshot optimization works."""

    # Find test screenshot
    test_screenshot = Path("screenshots").glob("*.png")
    screenshot_path = next(test_screenshot, None)

    if not screenshot_path or not screenshot_path.exists():
        print("⚠️ No test screenshot found")
        return True

    # Test optimization
    optimize_screenshot_for_vision(str(screenshot_path))

    print("✅ Screenshot optimization successful")
    return True


if __name__ == "__main__":
    test_screenshot_optimization()
```

## 📊 LangGraph Architecture with Prebuilt Components

This section details the revised graph architecture using LangGraph prebuilt components, memory, and observability nodes.

### Graph Structure

```python
from langgraph.graph import START, StateGraph, MessagesState, END
from langgraph.prebuilt import tools_condition, ToolNode
from langgraph.checkpoint.sqlite import SqliteSaver
from langchain_ollama import ChatOllama
from typing import Annotated
import os
from dotenv import load_dotenv

# Load environment variables
load_dotenv()

# Enable LangSmith (via environment variables)
# LANGCHAIN_API_KEY, LANGCHAIN_TRACING_V2, LANGCHAIN_PROJECT
# accessed via os.getenv() by LangChain automatically


# ============================================
# STATE DEFINITION
# ============================================
class RVAgentState(MessagesState):
    """
    Extended state for Android testing agent.

    Inherits MessagesState which provides:
    - messages: Annotated[List[BaseMessage], add_messages]

    Adds Android-specific tracking fields.
    """
    # Execution metadata
    iteration_count: int = 0
    tool_calls_total: int = 0

    # Android context
    app_package: str = ""
    objective: str = ""
    device_id: str = ""

    # UI state tracking
    current_activity: str = ""
    ui_elements_count: int = 0

    # Performance metrics
    screenshots_captured: int = 0
    actions_executed: int = 0


# ============================================
# NODES
# ============================================
def assistant_node(state: RVAgentState):
    """
    Assistant node - LLM reasoning with tool calling.

    Follows LangGraph course pattern:
    - Takes current state
    - Invokes LLM with tools
    - Returns message (with or without tool_calls)
    """
    # Get LLM configuration from environment
    model_name = os.getenv("OLLAMA_MODEL", "qwen-vision-tools-v1")

    llm = ChatOllama(
        model=model_name,
        temperature=0.25,
        top_p=0.8,
        top_k=50,
        num_predict=800,
        num_ctx=32768,
        base_url=os.getenv("OLLAMA_HOST", "http://localhost:11434")
    )

    # Bind tools (created externally)
    from rv_agent.tools.android_tools import AndroidToolManager
    tool_manager = AndroidToolManager(device_interface)
    tools = tool_manager.create_tools()
    llm_with_tools = llm.bind_tools(tools)

    # Invoke LLM
    response = llm_with_tools.invoke(state["messages"])

    # Update iteration count
    return {
        "messages": [response],
        "iteration_count": state["iteration_count"] + 1
    }


def metrics_node(state: RVAgentState):
    """
    Metrics tracking node for observability.

    Logs metrics to LangSmith (automatically) and local storage.
    Does not modify state (passthrough).
    """
    from rv_android_core.util.logging.manager import LoggingManager

    logger = LoggingManager.get_instance().get_logger("rv_agent.metrics")

    # Extract metrics
    last_message = state["messages"][-1]
    has_tool_calls = hasattr(last_message, 'tool_calls') and last_message.tool_calls

    metrics = {
        "iteration": state["iteration_count"],
        "total_tool_calls": state["tool_calls_total"],
        "message_count": len(state["messages"]),
        "has_tool_calls": has_tool_calls,
        "screenshots": state["screenshots_captured"],
        "actions": state["actions_executed"]
    }

    logger.info(f"[METRICS] {metrics}")

    # Empty return (no state changes)
    return {}


def screenshot_tracker_node(state: RVAgentState):
    """
    Screenshot tracking for observability.

    Monitors screenshot captures and optimizations.
    """
    # Check if last tool call was screenshot
    last_message = state["messages"][-1]
    if hasattr(last_message, 'tool_calls'):
        for tool_call in last_message.tool_calls:
            if tool_call.get('name') == 'capture_screenshot':
                return {"screenshots_captured": state["screenshots_captured"] + 1}

    return {}


# ============================================
# GRAPH CONSTRUCTION (USING PREBUILT!)
# ============================================
def create_agent_graph(checkpointer_db: str = ":memory:"):
    """
    Create LangGraph agent using prebuilt components.

    Architecture:
      START → assistant → tools_condition
                          ├─ tools → metrics → screenshot_tracker → assistant
                          └─ END

    Args:
        checkpointer_db: SQLite database path (":memory:" or "checkpoints.db")

    Returns:
        Compiled builder with memory
    """
    # Initialize checkpoint for memory
    memory = SqliteSaver.from_conn_string(checkpointer_db)

    # Create builder
    builder = StateGraph(RVAgentState)

    # Add nodes
    builder.add_node("assistant", assistant_node)
    builder.add_node("tools", ToolNode(tools))  # PREBUILT!
    builder.add_node("metrics", metrics_node)
    builder.add_node("screenshot_tracker", screenshot_tracker_node)

    # Define edges
    builder.add_edge(START, "assistant")

    # Use prebuilt tools_condition for routing
    # Automatically routes to "tools" if tool_calls present, otherwise END
    builder.add_conditional_edges(
        "assistant",
        tools_condition,  # PREBUILT ROUTING!
    )

    # After tools execution, flow through observability nodes
    builder.add_edge("tools", "metrics")
    builder.add_edge("metrics", "screenshot_tracker")
    builder.add_edge("screenshot_tracker", "assistant")  # Loop back

    # Compile with memory
    graph = builder.compile(
        checkpointer=memory,  # Enables state persistence!
        interrupt_before=[]   # Can add breakpoints for debugging
    )

    return graph
```

```python
"""
Screenshot optimization for vision models.

This module provides utilities to optimize screenshots for multimodal LLM input,
reducing token cost and inference time while preserving UI element visibility.
"""

import base64
from io import BytesIO
from pathlib import Path
from typing import Optional, Tuple

from PIL import Image

from rv_android_core.util.logging.manager import LoggingManager
from rv_android_core.util.logging.constants import CONTEXT_COMPONENT


class ScreenshotOptimizer:
    """
    Optimizes screenshots for vision model processing.

    ### Architectural Decisions:
    - Uses PIL for image processing with quality-preserving resizing
    - Implements JPEG compression with configurable quality settings
    - Converts RGBA to RGB for smaller payload size
    - Maintains aspect ratio during resizing to preserve UI layout
    - Provides detailed optimization metrics for monitoring

    ### Role in the System:
    - Reduces token cost for multimodal LLM requests by 50-70%
    - Improves inference speed through smaller image payloads
    - Preserves UI element visibility for accurate identification
    - Enables efficient multimodal context in agent state

    ### Optimization Strategy:
    - Target resolution: 728x1288 (26×28 by 46×28 - Qwen2.5-VL requirement)
    - JPEG quality: 85% (imperceptible quality loss for UI elements)
    - Format: JPEG for compressed size vs PNG lossless
    - Resampling: LANCZOS for high-quality downscaling
    - Token cost: ~1,196 tokens per image (within optimal 256-1280 range)
    """

    # Default optimization parameters validated for Qwen2.5-VL
    # Dimensions MUST be multiples of 28 for Qwen2.5-VL
    DEFAULT_TARGET_SIZE = (728, 1288)  # 26×28 by 46×28, 9:16 aspect ratio
    DEFAULT_QUALITY = 85  # Balance between size and clarity
    DEFAULT_FORMAT = "JPEG"  # Smaller than PNG for UI screenshots

    def __init__(self):
        """Initialize screenshot optimizer with logging."""
        logging_manager = LoggingManager.get_instance()
        self.logger = logging_manager.get_logger(
            "rv_agent.screenshot_optimizer",
            {CONTEXT_COMPONENT: "ScreenshotOptimizer"}
        )

    def optimize(
        self,
        image_path: str,
        target_size: Optional[Tuple[int, int]] = None,
        quality: Optional[int] = None,
        output_format: Optional[str] = None
    ) -> Optional[str]:
        """
        Optimize screenshot for vision model input.

        Args:
            image_path: Path to screenshot file
            target_size: Target (width, height) tuple, uses DEFAULT_TARGET_SIZE if None
            quality: JPEG quality 1-100, uses DEFAULT_QUALITY if None
            output_format: Output format (JPEG or PNG), uses DEFAULT_FORMAT if None

        Returns:
            Base64 encoded optimized image, or None if optimization fails
        """
        target_size = target_size or self.DEFAULT_TARGET_SIZE
        quality = quality or self.DEFAULT_QUALITY
        output_format = output_format or self.DEFAULT_FORMAT

        try:
            # Validate input file exists
            img_path = Path(image_path)
            if not img_path.exists():
                self.logger.error(f"Screenshot file not found: {image_path}")
                return None

            original_size = img_path.stat().st_size

            # Load image
            img = Image.open(image_path)
            self.logger.debug(f"Loaded screenshot: {img.size[0]}x{img.size[1]}, mode={img.mode}")

            # Convert RGBA to RGB for JPEG compression
            if img.mode == 'RGBA' and output_format == "JPEG":
                # Create white background to replace transparency
                background = Image.new('RGB', img.size, (255, 255, 255))
                background.paste(img, mask=img.split()[3])  # Use alpha channel as mask
                img = background
                self.logger.debug("Converted RGBA to RGB for JPEG compression")

            # Resize maintaining aspect ratio
            # thumbnail() modifies in-place and preserves aspect ratio
            img.thumbnail(target_size, Image.Resampling.LANCZOS)
            self.logger.debug(f"Resized to: {img.size[0]}x{img.size[1]}")

            # Encode to bytes
            buffer = BytesIO()
            img.save(buffer, format=output_format, quality=quality, optimize=True)
            encoded = base64.b64encode(buffer.getvalue()).decode("utf-8")

            # Log optimization metrics
            optimized_size = len(encoded)
            reduction = (1 - optimized_size / original_size) * 100

            self.logger.info(
                f"Screenshot optimized: {original_size:,} -> {optimized_size:,} bytes "
                f"({reduction:.1f}% reduction), dimensions: {img.size}"
            )

            return encoded

        except Exception as e:
            self.logger.error(f"Screenshot optimization failed: {e}", exc_info=True)
            return None

    def optimize_with_fallback(self, image_path: str) -> Optional[str]:
        """
        Optimize screenshot with fallback to original encoding.

        If optimization fails, falls back to basic base64 encoding
        without modifications.

        Args:
            image_path: Path to screenshot file

        Returns:
            Base64 encoded image (optimized or original)
        """
        # Try optimization first
        optimized = self.optimize(image_path)
        if optimized:
            return optimized

        # Fallback to basic encoding
        self.logger.warning("Using fallback encoding without optimization")
        try:
            with open(image_path, "rb") as f:
                return base64.b64encode(f.read()).decode("utf-8")
        except Exception as e:
            self.logger.error(f"Fallback encoding failed: {e}")
            return None
```

### 3. Smart UI Interaction with Explicit Waits

#### Replace Fixed Sleeps

```python
from typing import Callable, Optional
import time

class DeviceInterface:
    def wait_for_condition(
        self,
        condition: Callable[[], bool],
        timeout: int = 10,
        poll_interval: float = 0.5,
        error_msg: str = "Condition not met"
    ) -> bool:
        """
        Wait for condition to be true.

        More robust than fixed time.sleep() delays.
        """
        start = time.time()
        while time.time() - start < timeout:
            if condition():
                return True
            time.sleep(poll_interval)

        raise TimeoutError(f"{error_msg} after {timeout}s")

    def click_and_wait(
        self,
        x: int,
        y: int,
        wait_for: Optional[Callable] = None
    ) -> bool:
        """Click and wait for UI change."""
        # Take before screenshot for comparison
        before_state = self.get_current_ui_state()

        # Execute click
        success = self.click(x, y)
        if not success:
            return False

        # Wait for UI to change
        if wait_for:
            self.wait_for_condition(wait_for)
        else:
            # Default: wait for UI state to differ
            self.wait_for_condition(
                lambda: self.get_current_ui_state() != before_state,
                timeout=5,
                error_msg="UI did not change after click"
            )

        return True
```

```python
class StateSummarizer:
    """
    Summarize conversation history for long sessions.

    Prevents token overflow from long message lists.
    """

    def summarize_messages(
        self,
        messages: List[BaseMessage],
        max_messages: int = 20
    ) -> List[BaseMessage]:
        """Keep recent messages, summarize old ones."""
        if len(messages) <= max_messages:
            return messages

        # Keep system message and recent messages
        system_msgs = [m for m in messages if isinstance(m, SystemMessage)]
        recent_msgs = messages[-max_messages:]

        # Summarize middle messages
        middle_msgs = messages[len(system_msgs):-max_messages]
        summary = self._create_summary(middle_msgs)

        return system_msgs + [HumanMessage(content=summary)] + recent_msgs

    def _create_summary(self, messages: List[BaseMessage]) -> str:
        """Create summary of message sequence."""
        tool_calls = sum(1 for m in messages if hasattr(m, 'tool_calls'))
        return f"[Summary: {len(messages)} messages, {tool_calls} tool executions]"
```

```python
    """

    def __init__(self):
        self.action_metrics = defaultdict(ActionMetrics)
        self.session_health = {
            "start_time": time.time(),
            "last_success": time.time(),
            "consecutive_failures": 0
        }

    def record_action(self, action_type: str, success: bool):
        """Record action outcome."""
        metrics = self.action_metrics[action_type]
        metrics.total += 1

        if success:
            metrics.successful += 1
            self.session_health["last_success"] = time.time()
            self.session_health["consecutive_failures"] = 0
        else:
            metrics.failed += 1
            self.session_health["consecutive_failures"] += 1

    def get_health_status(self) -> dict:
        """Get session health indicators."""
        time_since_success = time.time() - self.session_health["last_success"]

        return {
            "healthy": self.session_health["consecutive_failures"] < 5,
            "time_since_last_success": time_since_success,
            "consecutive_failures": self.session_health["consecutive_failures"],
            "action_success_rates": {
                action: metrics.success_rate
                for action, metrics in self.action_metrics.items()
            }
        }

    def should_terminate_session(self) -> bool:
        """Determine if session should terminate due to poor health."""
        health = self.get_health_status()

        # Terminate if too many consecutive failures
        if health["consecutive_failures"] >= 10:
            return True

        # Terminate if no success in 5 minutes
        if health["time_since_last_success"] > 300:
            return True

        return False
```

   - Health monitoring and auto-termination
