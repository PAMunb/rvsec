## ❌ NEW ISSUE: Routing Condition Failing

### Problem Description

**Symptoms:**
- Tool calls being generated by assistant_node
- `_tools_condition` NOT routing to tools node
- 0 tool executions (no "TOOLS: Executing tool calls" logs)
- All actions marked as UNKNOWN

### Root Cause Investigation

The `_tools_condition` function is returning "end" when it should return "tools".

**Possible causes:**
1. Messages not properly merged into state before condition runs
2. State passed to condition doesn't include messages from assistant_node
3. LangGraph executing condition before state update completes
4. Message clearing in observe_node interfering with routing

```python
def _tools_condition(self, state: AgentState) -> str:
    messages = state.get("messages", [])
    logger.info(f"🔀 ROUTING: Checking tool calls, messages count: {len(messages)}")

    if not messages:
        logger.warning("   No messages in state")
        return "end"

    last_message = messages[-1]
    logger.info(f"   Last message type: {type(last_message)}")

    if hasattr(last_message, 'tool_calls'):
        logger.info(f"   Tool calls present: {len(last_message.tool_calls) if last_message.tool_calls else 0}")
        if last_message.tool_calls:
            logger.info("   ✅ Routing to tools")
            return "tools"

    logger.info("   ⏭️  Routing to end (learn)")
    return "end"
```
