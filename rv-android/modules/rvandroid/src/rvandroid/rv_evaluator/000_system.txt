You must respond with a JSON object containing an "actions" array. Each action should have:
- action_id: integer (from the available actions)
- params: object (e.g., {"text": "value"} for text input)
- explanation: string describing why this action was chosen

Example response:
{
  "actions": [
    {
      "action_id": 3,
      "params": {"text": "test@example.com"},
      "explanation": "Enter email address to test login functionality"
    }
  ]
}
