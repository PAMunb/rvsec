# Scope Ledger — gh62-aspectj-grammar-coverage

**Purpose**: snapshot of bucket assignments for every SILENT-GAP and EXPLICIT-NO-OP matrix row at gh62 archive time. NOT maintained after archive (see design D4); the live source of truth for open work is `docs/aspectj_grammar_coverage.md` itself (any row with `Verdict = SILENT-GAP` is by definition outstanding).

**Frozen snapshot tripwire**: SHA-256 of this file is committed to `rvsec-android/rvsec-instrumentation-dexlib2/grammar-tests/src/test/resources/ledger.snapshot.sha256` per design D7. `MatrixIntegrityTest.testSilentGapRowsHaveDisabledTestAndLedgerEntry` reads both files and fails the build if they diverge (positive enforcement of the "frozen post-archive" property).

**What is NOT in this ledger**:

- `Verdict = NOT-NEEDED` rows (path α: zero demand + no impl; path β: production absorbed by upstream toolchain stage). These are not open work by construction. The four NOT-NEEDED β rows (`handler`, `declare precedence`, `aspect Foo`, `pointcut p():`) appear in the matrix but NOT here. The Round-3 SILENT-GAP-permanent sub-bucket is eliminated.
- `Verdict = COVERED` rows. These include the round-6 in-change closures: the eight demand-driven gap closures (`condition(...)` guard emit per §4.G, positive `within(typePattern)` per §4.W, `T+` in `call()` owner per §4.O, `!target(T)`/`!args(T)` parser specialization per §4.N, method-name glob `name*` per §4.X, `__STATICSIG` macro support per §4.S, `staticinitialization` synthesis per §4.Y, `after() throwing(...)` end-to-end install per §4.T) plus the `NamedRefPC` resolver via `getCommonPointcut()` per §4.D.
- AspectJ extensions outside the closed enumeration (`lock`/`unlock` per OQ3; per-clauses / ITDs / `declare warning/error/soft` / annotation-style aspects / generics in type patterns per OQ4).

**Demand counts**: per-corpus integer counts in this ledger are **provisional** and will be regenerated by `DemandCounter` (tasks §1.0) before matrix population. Bucket assignments may shift if regenerated counts differ materially from the round-4 baseline.
