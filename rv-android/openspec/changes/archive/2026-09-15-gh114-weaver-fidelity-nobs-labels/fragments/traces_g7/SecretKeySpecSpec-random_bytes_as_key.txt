# Random bytes used as key material. An application fills a fresh 32-byte array from an observed
# SecureRandom it constructed itself and wraps it as an AES key. SecureRandomSpec accepts the
# sequence and marks the array `randomized`; SecretKeySpec.crysl requires `preparedKeyMaterial`,
# which only a key's `getEncoded()` ensures, so `SecretKeySpecSpec.c1` still reports, and the
# array carries no REPORTED_UPSTREAM mark.
#
# After gh114: SECRETKEYSPEC-NOBS-03, label `random-key-material`, with `vfp` over the array, and
# not SECRETKEYSPEC-NOBS-00. The constructed spec is marked REPORTED_UPSTREAM.
# Before gh114: the same (spec, event), `SecretKeySpecSpec.c1`, reported SECRETKEYSPEC-NOBS-00.
bind raw = bytes(32)
new SecureRandom() -> r
r.nextBytes(raw)
new SecretKeySpec(raw, "AES") -> spec
