# CONSTRAINTS clause admits neither it nor any alias of it (alias_table.csv has no

# Seed: g3 fires outside the automaton and accuses InvalidSequenceOfMethodCalls,
# its __RESET drops the monitor to the start state, where initSign is not declared
# and accuses a second time, and SIGNATURE-ALG-00 is never reached. After: g1 binds
# the signature, the run reaches the accepting state, and SIGNATURE-ALG-00 stands
# alone.
