# The accusing control of ledger #36, and the one the platform does not refuse for us. Measured
# on Temurin 21: `tmf.init(store)` on a PKCS12 store that was never loaded RUNS -- unlike
# `kmf.init(store, pw)`, which raises KeyStoreException on the same object -- so a trust manager
# factory really can be built over a key store nothing ever initialised, and only this read says
# so. The store is `bind`ed rather than dispatched, so no getInstance and no load reach the
# monitor and the object arrives at init carrying nothing.
bind ks = KeyStore.getInstance("PKCS12")
TrustManagerFactory.getInstance("PKIX") -> tmf
tmf.init(ks)
