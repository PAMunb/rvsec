# The four-argument constructor with a tag length api30 does not admit, over
# randomised material. The offset and length are in range, so the JDK builds the
# object and the `after ... returning` advice runs -- an out-of-range pair cannot
# be traced at all, because the constructor's documented contract throws
# IllegalArgumentException before any advice sees it.
bind iv = bytes(16)
SecureRandom.getInstance("SHA1PRNG") -> r
r.nextBytes(iv)
new GCMParameterSpec(64, iv, 0, 16) -> spec
