# The two-argument constructor with a tag length outside api30's
# `tLen in {128, 120, 96, 112, 104}`, over material a SecureRandom produced. The
# CONSTRAINTS clause is broken and the REQUIRES clause holds, which is the
# separation the composite guard could not report: 64 is a legal argument to the
# JDK constructor (it rejects only a negative tLen), so the object is built and
# the advice runs.
bind iv = bytes(16)
SecureRandom.getInstance("SHA1PRNG") -> r
r.nextBytes(iv)
new GCMParameterSpec(64, iv) -> spec
