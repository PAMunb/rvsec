# violating branch: a transformation no table admits. The key is bound for the
# same reason CipherSpec.txt binds one -- `c.init(1, null)` is an ambiguous call
# javac rejects, and an unnamed overload is not a program the woven monitor can
# see.
#
# The ordering reports at `i2` and `f2` are CIPHER-ORDER-03, label `creation-refused`: the
# refused `getInstance` (g3) sets `creationRefused`, and the automaton admits no use of a
# Cipher whose transformation it refused.
bind k = new SecretKeySpec(bytes, "AES")
Cipher.getInstance("DES") -> c
c.init(1, k)
c.doFinal(bytes)
