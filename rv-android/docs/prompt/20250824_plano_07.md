## **Simple Configuration System**

### **Strategy Configuration Files**

**Location**: Configuration files in `configs/strategy_variants/`

```json
// single_enhanced.json
{
  "strategy_name": "single_enhanced",
  "base_strategy": "single",
  "coverage_enabled": true,
  "ui_coverage_tracker": true
}

// mop_vision.json  
{
  "strategy_name": "mop_vision",
  "base_strategy": "vision", 
  "coverage_enabled": true,
  "ui_coverage_tracker": true,
  "context_intelligence": true
}
```

### **Simple Configuration Loader**

```python
"""
Simple configuration loader for strategy variants.
"""

import json
from pathlib import Path
from typing import Dict, Any, Optional

from rv_android_core.util.logging.manager import LoggingManager


class ConfigLoader:
    """Load strategy configurations from JSON files."""
    
    def __init__(self, config_dir: str = "configs/strategy_variants"):
        self.config_dir = Path(config_dir)
        
        # Set up logging
        logging_manager = LoggingManager.get_instance()
        self.logger = logging_manager.get_logger(
            "rv_android_core.config.config_loader",
            {"component": "ConfigLoader"}
        )
    
    def load_strategy_config(self, strategy_name: str) -> Optional[Dict[str, Any]]:
        """Load configuration for specific strategy."""
        config_file = self.config_dir / f"{strategy_name}.json"
        
        if not config_file.exists():
            self.logger.warning(f"Config file not found: {config_file}")
            return None
        
        try:
            with open(config_file, 'r') as f:
                config = json.load(f)
            
            self.logger.info(f"Loaded config for {strategy_name}")
            return config
            
        except Exception as e:
            self.logger.error(f"Error loading config {config_file}: {e}")
            return None
    
    def get_available_strategies(self) -> list[str]:
        """Get list of available strategy configurations."""
        if not self.config_dir.exists():
            return []
            
        return [f.stem for f in self.config_dir.glob("*.json")]
```

## **Usage Example**

```python
# Load simple strategy configuration
config_loader = ConfigLoader()
strategy_config = config_loader.load_strategy_config("mop_vision")

if strategy_config:
    # Use configuration to initialize strategy
    strategy = MOPVisionStrategy(
        name=strategy_config["strategy_name"],
        coverage_enabled=strategy_config.get("coverage_enabled", False),
        context_intelligence=strategy_config.get("context_intelligence", False)
    )
```

### **Integration with Existing Tools**

Tools already declare their own variants through existing mechanisms:
- rvandroid-tool registers strategy variants via LLMComponentFactory
- No need for complex hierarchical configuration management
- Simple JSON loading provides sufficient flexibility

### **Benefits of Simplified Approach**
- **Direct**: No intermediate layers or complex variant management
- **Maintainable**: Easy to understand and modify configuration files
- **Sufficient**: Meets all requirements without over-engineering
- **Compatible**: Works with existing tool registration systems
