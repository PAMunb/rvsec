## **Implementation Overview**

### **Balanced Implementation**
- **UICoverageTracker**: Element tracking with essential analytics for LLM
- **Coverage Annotations**: [UNTESTED]/[TESTED-Nx] markers with interaction counts
- **Action Distribution**: Track action types for balanced testing
- **Simple Statistics**: Basic coverage percentages and element counts

### **LLM Decision Support**  
- **Element Priority**: Highlight untested elements for systematic exploration
- **Interaction Frequency**: Show element usage patterns (tested 1x, 3x, etc.) 
- **Action Balance**: Guide LLM toward underused action types
- **Coverage Progress**: Show testing progress to encourage thoroughness

### **UICoverageTracker Class**
**Location**: `modules/rvandroid-tool/src/rvandroid_tool/core/memory/ui_coverage_tracker.py`

```python
"""
UI coverage tracking for systematic element exploration.

This module provides tracking of UI element interactions during
testing, using Set() storage for memory efficiency and annotations
for LLM guidance.
"""

from typing import Set, Dict, Any, Optional, List
from dataclasses import dataclass
import hashlib

from rv_android_core.util.error.error_handler import ErrorHandler
from rv_android_core.util.logging.manager import LoggingManager
from rv_llm.llm.constants import StateEntry


@dataclass
class CoverageStats:
    """Coverage statistics"""
    total_elements: int = 0
    tested_elements: int = 0
    untested_elements: int = 0
    
    @property
    def coverage_percentage(self) -> float:
        if self.total_elements == 0:
            return 0.0
        return (self.tested_elements / self.total_elements) * 100


class UICoverageTracker:
    """
    Balanced UI element coverage tracking for LLM decision-making.
    
    Provides essential analytics to help LLM make informed decisions about
    which elements to test while maintaining simplicity.
    
    ### Key Features:
    - Element interaction tracking with counts (for systematic testing)
    - Action type distribution monitoring (for balanced exploration)
    - Coverage annotations for LLM guidance ([UNTESTED], [TESTED-Nx])
    - Simple statistics without over-engineering
    """
    
    def __init__(self):
        # Set up logging
        logging_manager = LoggingManager.get_instance()
        self.logger = logging_manager.get_logger(
            "rvandroid_tool.core.memory.ui_coverage_tracker",
            {"component": "UICoverageTracker"}
        )
        
        # Element tracking: element_id -> interaction_count  
        self.tested_elements: Dict[str, int] = {}
        
        # Action type distribution for balance guidance
        self.action_type_counts: Dict[str, int] = {}
        
        # Screen tracking: screen_hash -> set of element_ids
        self.screen_elements: Dict[str, Set[str]] = {}
        
        self.logger.info("UICoverageTracker initialized")
    
    def record_interaction(self, element_id: str, action_type: str = "click", screen_hash: Optional[str] = None) -> None:
        """
        Record element interaction with action type for balanced guidance.
        
        Args:
            element_id: Unique identifier for the UI element
            action_type: Type of action (click, set_text, coordinate, etc.)
            screen_hash: Optional screen hash for context
        """
        try:
            # Track element interaction count (essential for LLM decisions)
            self.tested_elements[element_id] = self.tested_elements.get(element_id, 0) + 1
            
            # Track action type distribution (helps prevent testing bias)
            self.action_type_counts[action_type] = self.action_type_counts.get(action_type, 0) + 1
            
            # Track screen elements if screen_hash provided
            if screen_hash:
                if screen_hash not in self.screen_elements:
                    self.screen_elements[screen_hash] = set()
                self.screen_elements[screen_hash].add(element_id)
            
            self.logger.debug(f"Recorded interaction: {element_id} ({action_type}, count: {self.tested_elements[element_id]})")
            
        except Exception as e:
            self.logger.error(f"Error recording interaction {element_id}: {e}")
    
    def get_coverage_stats(self, screen_hash: Optional[str] = None) -> CoverageStats:
        """
        Get coverage statistics.
        
        Args:
            screen_hash: Optional screen to get stats for (or global if None)
            
        Returns:
            CoverageStats with basic coverage information
        """
        if screen_hash and screen_hash in self.screen_elements:
            # Screen-specific stats
            screen_element_ids = self.screen_elements[screen_hash]
            tested_on_screen = sum(1 for elem_id in screen_element_ids 
                                 if elem_id in self.tested_elements)
            
            return CoverageStats(
                total_elements=len(screen_element_ids),
                tested_elements=tested_on_screen,
                untested_elements=len(screen_element_ids) - tested_on_screen
            )
        else:
            # Global stats
            # Global stats (across all screens)
            all_elements = set()
            for screen_set in self.screen_elements.values():
                all_elements.update(screen_set)
            
            return CoverageStats(
                total_elements=len(all_elements),
                tested_elements=len(self.tested_elements),
                untested_elements=len(all_elements) - len(self.tested_elements)
            )
    
    def annotate_screen_elements(self, screen_description, screen_hash: str) -> str:
        """
        Add [UNTESTED]/[TESTED] annotations to screen description.
        
        Args:
            screen_description: Screen description to annotate
            screen_hash: Hash of current screen
            
        Returns:
            Annotated screen description string
        """
        if not hasattr(screen_description, 'items'):
            return str(screen_description)
        
        # Track elements on this screen
        if screen_hash not in self.screen_elements:
            self.screen_elements[screen_hash] = set()
        
        annotated_items = []
        
        for item in screen_description.items:
            for action in item.actions:
                element_id = f"{action.id}_{action.text}"
                
                # Track element
                self.screen_elements[screen_hash].add(element_id)
                
                # Add annotation with frequency (important for LLM decisions)
                if element_id in self.tested_elements:
                    count = self.tested_elements[element_id]
                    if count == 1:
                        annotation = "[TESTED-1x]"
                    elif count <= 3:
                        annotation = f"[TESTED-{count}x]" 
                    else:
                        annotation = "[WELL-TESTED]"
                else:
                    annotation = "[UNTESTED]"  # Highest priority for LLM
                
                action.text = f"{annotation} {action.text}"
                annotated_items.append(item)
        
        return str(screen_description)
    
    def get_untested_elements(self, screen_hash: str) -> List[str]:
        """Get list of untested element IDs for a screen (essential for LLM prioritization)."""
        if screen_hash not in self.screen_elements:
            return []
            
        return [elem_id for elem_id in self.screen_elements[screen_hash]
                if elem_id not in self.tested_elements]
    
    def get_action_balance_guidance(self) -> str:
        """
        Get action balance guidance for LLM decision-making.
        
        Returns:
            Simple guidance string about action type distribution
        """
        if not self.action_type_counts:
            return "Action Balance: Vary between click, text input, and coordinate actions"
        
        total_actions = sum(self.action_type_counts.values())
        
        guidance = []
        
        # Check if click actions are over-represented (>60%)
        click_pct = (self.action_type_counts.get('click', 0) / total_actions) * 100
        if click_pct > 60:
            guidance.append("Consider more SET_TEXT and coordinate actions")
        
        # Check if text actions are under-represented (<20%)
        text_pct = (self.action_type_counts.get('set_text', 0) / total_actions) * 100
        if text_pct < 20 and self.action_type_counts.get('set_text', 0) > 0:
            guidance.append("Text input actions are underused")
        
        if not guidance:
            return "Action Balance: Good distribution of action types"
        
        return f"Action Balance: {', '.join(guidance)}"
    
    def get_coverage_summary(self, screen_hash: Optional[str] = None) -> str:
        """
        Get coverage summary for LLM context.
        
        Returns:
            Simple summary string for LLM guidance
        """
        stats = self.get_coverage_stats(screen_hash)
        
        if stats.total_elements == 0:
            return "Coverage: No elements tracked yet"
        
        return f"Coverage: {stats.tested_elements}/{stats.total_elements} elements tested ({stats.coverage_percentage:.0f}%)"
    
    def clear(self) -> None:
        """Clear all tracking data."""
        self.tested_elements.clear()
        self.action_type_counts.clear()  
        self.screen_elements.clear()
        self.logger.info("Coverage tracking data cleared")

    def _compute_screen_hash(self, state: Dict[str, Any]) -> Optional[str]:
        """
        Compute screen hash using existing system components.
        
        Uses MemoryManager hash when available, falls back to VIEW_TREE structure.
        
        Args:
            state: Current application state
            
        Returns:
            Screen hash string or None if computation fails
        """
        try:
            # Use existing system hash (preferred)
            existing_hash = state.get(StateEntry.HASH_SCREEN)
            if existing_hash:
                return existing_hash
                
            # Use VIEW_TREE structure when available
            view_tree = state.get(StateEntry.VIEW_TREE)
            if view_tree:
                # Use existing MemoryManager hash approach
                hash_data = str(view_tree)[:200]  # First 200 chars for structure
                return hashlib.md5(hash_data.encode()).hexdigest()[:8]
                
            # Final fallback: activity only
            activity = state.get(StateEntry.ACTIVITY, "unknown")
            return hashlib.md5(activity.encode()).hexdigest()[:8]
            
        except Exception:
            return None
```

## **Simple LLM Guidance Fragment**

### **CoverageGuidanceFragment**
**Location**: `modules/rvandroid-tool/src/rvandroid_tool/llm/prompt/fragments/coverage_guidance_fragment.py`

```python
"""
Simple coverage guidance fragment for LLM decision support.
"""

from typing import Dict, Any
from rv_llm.llm.prompt.information.base_fragment import InformationFragment


class CoverageGuidanceFragment(InformationFragment):
    """
    Simple fragment providing essential coverage guidance for LLM prompts.
    """
    
    def __init__(self, ui_coverage_tracker=None):
        super().__init__()
        self.ui_coverage_tracker = ui_coverage_tracker
    
    def generate(self, context: Dict[str, Any]) -> str:
        """
        Generate essential coverage guidance for LLM.
        
        Args:
            context: Template context with state information
            
        Returns:
            Simple coverage guidance string
        """
        if not self.ui_coverage_tracker:
            return ""
        
        state = context.get('state', {})
        screen_hash = self.ui_coverage_tracker._compute_screen_hash(state)
        
        if not screen_hash:
            return ""
        
        guidance_parts = []
        
        # Add coverage summary for LLM context
        coverage_summary = self.ui_coverage_tracker.get_coverage_summary(screen_hash)
        guidance_parts.append(coverage_summary)
        
        # Add action balance guidance 
        balance_guidance = self.ui_coverage_tracker.get_action_balance_guidance()
        guidance_parts.append(balance_guidance)
        
        # Add priority guidance
        untested_count = len(self.ui_coverage_tracker.get_untested_elements(screen_hash))
        if untested_count > 0:
            guidance_parts.append(f"Priority: {untested_count} [UNTESTED] elements available")
        
        return " | ".join(guidance_parts) if guidance_parts else ""
```

## **Balanced Implementation Summary**

### **What was maintained for LLM decision-making:**
1. **Element interaction tracking** - Essential for systematic testing
2. **Action type distribution** - Prevents testing bias toward click actions
3. **Coverage annotations** - [UNTESTED], [TESTED-1x], [WELL-TESTED] markers
4. **Simple statistics** - Coverage percentages and element counts
5. **Priority guidance** - Highlights untested elements

### **What was simplified:**
1. **Removed complex analytics** - No pattern learning or advanced statistics
2. **Simple guidance methods** - Direct, actionable feedback for LLM
3. **Essential storage only** - Element counts and action type distribution
4. **Focused fragment** - Only essential guidance information

This provides sufficient information for LLM decision-making without over-engineering (~300 lines vs 1,642 lines).
