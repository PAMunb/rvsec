## **MOPVisionStrategy Simplified**

### **Design Rationale**
The MOPVisionStrategy extends VisionStrategy with minimal additions. No need for complex screen pattern analysis, caching, or historical pattern learning. Simple M/DM counting and basic guidance is sufficient.

```python
"""
Context-intelligent strategy for monitored operations discovery using multimodal analysis.

This module implements the MOPVisionStrategy class, extending VisionStrategy with
context-aware screen analysis and intelligent action sequencing for systematic
monitored operations violation discovery.
"""

from typing import Dict, Any, Optional, List, Set
from datetime import datetime

from rv_android_core.constants import MOP_STRATEGY_CONSTANTS
from rv_android_core.util.error.error_handler import ErrorHandler
from rv_android_core.util.error.exceptions import StrategyError
from rv_android_core.util.logging.constants import CONTEXT_COMPONENT
from rv_android_core.util.logging.manager import LoggingManager
from rv_llm.llm.constants import StateEntry, ContextMode
from rvandroid_tool.llm.prompt.strategies.vision_strategy import VisionStrategy
from rv_screen_parser.parser.screen.visitor.model import ScreenDescription, ItemAction


class MOPVisionStrategy(VisionStrategy):
    """
    Context-intelligent multimodal strategy for monitored operations discovery.
    
    ### Architectural Decisions:
    - **Strategy Extension**: Inherits all VisionStrategy capabilities including multimodal 
      processing, coordinate actions, and context mode support
    - **Context Intelligence**: Adds screen pattern recognition and action sequencing logic
    - **Universal Compatibility**: Maintains compatibility with both STATELESS and RICH context modes
    - **Performance Optimization**: Implements caching for expensive context analysis operations
    
    ### Role in the System:
    - **Screen Analysis**: Automatically detects UI patterns (forms, navigation, configuration)
    - **Sequence Intelligence**: Provides logical action ordering based on screen context
    - **Pattern Learning**: Learns from successful violation discovery for strategy refinement
    - **History Enhancement**: Enriches sliding window history with monitored operations insights
    
    ### Integration Points:
    - VisionStrategy base class for multimodal and coordinate action support
    - Template system through mop_vision.xml template extension
    - Fragment system via enhanced variable generation for prompt context
    - Memory systems for both STATELESS and RICH context mode operation
    """
    
    DEFAULT_TEMPLATE = "mop_vision"
    
    def __init__(self, 
                 name: str = "mop_vision", 
                 context_mode: str = ContextMode.STATELESS, 
                 **kwargs):
        """
        Initialize context-intelligent monitored operations strategy.
        
        Configures the strategy with the same context_mode support as VisionStrategy
        while adding monitored operations specific analysis capabilities.
        
        Args:
            name: Strategy identifier for registration and template selection
            context_mode: Context enrichment mode (STATELESS or RICH)
            **kwargs: Additional configuration parameters for base strategy
        """
        super().__init__(name, context_mode=context_mode, **kwargs)
        
        # Initialize logging infrastructure
        logging_manager = LoggingManager.get_instance()
        self.logger = logging_manager.get_logger(
            "rvandroid_tool.llm.prompt.strategies.mop_vision_strategy",
            {CONTEXT_COMPONENT: "MOPVisionStrategy"}
        )
        
        # Initialize error handling
        self.error_handler = ErrorHandler.get_instance()
        
        # No pattern analyzer needed - keep it simple
        
        self.logger.info(f"Initialized MOP Vision Strategy with context_mode: {context_mode}")
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy",
        phase="template_variable_building"
    )
    def _build_template_variables(self, 
                                 state: Dict[str, Any], 
                                 context: Dict[str, Any], 
                                 information: Dict[str, Any]) -> Dict[str, Any]:
        """
        Build template variables with monitored operations context intelligence.
        
        Extends VisionStrategy variable building with context-aware analysis including
        screen pattern detection, action sequence suggestions, and violation insights.
        
        Args:
            state: Current application state with UI and coverage information
            context: Testing context and configuration parameters
            information: Fragment-generated information for prompt construction
            
        Returns:
            Enhanced template variables with monitored operations intelligence
            
        Raises:
            StrategyError: If template variable building fails
        """
        try:
            # Get base variables from VisionStrategy (includes all context_mode logic)
            variables = super()._build_template_variables(state, context, information)
            
            # Add simple MOP context intelligence
            variables['mop_screen_context'] = self._analyze_screen_context(state)
            variables['mop_action_sequence'] = self._suggest_action_sequence(state)
            
            # RICH context mode uses existing VisionStrategy implementation
            
            return variables
            
        except Exception as e:
            raise StrategyError(f"Failed to build MOP template variables: {e}") from e
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy",
        phase="screen_context_analysis"
    )
    def _analyze_screen_context(self, state: Dict[str, Any]) -> str:
        """
        Simple screen context analysis - just count M/DM actions.
        
        Args:
            state: Current application state containing screen information
            
        Returns:
            Basic context guidance for monitored operations discovery
        """
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if not screen_description:
            return ""
        
        # Simple M/DM counting
        dm_count = sum(1 for item in screen_description.items 
                      for action in item.actions 
                      if getattr(action, 'directly_reaches_mop', False))
        
        if dm_count >= 2:
            return "Focus on [DM] - multiple direct MOP actions available"
        elif dm_count >= 1:
            return "Focus on [DM] - direct MOP action available"
        else:
            return "Explore systematically for MOP actions"
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy",
        phase="action_sequence_suggestion"
    )
    def _suggest_action_sequence(self, state: Dict[str, Any]) -> str:
        """
        Simple action sequence suggestions based on MOP priorities.
        
        Args:
            state: Current application state with screen information
            
        Returns:
            Basic sequence guidance for monitored operations testing
        """
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if not screen_description:
            return ""
        
        # Count [DM] actions
        dm_count = sum(1 for item in screen_description.items 
                      for action in item.actions 
                      if getattr(action, 'directly_reaches_mop', False))
        
        if dm_count > 0:
            return "1. Test [DM] actions first for direct MOP access 2. Test other elements systematically"
        else:
            return "Explore screen systematically to discover MOP actions"
        
        # Simple priority-based suggestions
        dm_actions = []
        m_actions = []
        
        for item in screen_description.items:
            for action in item.actions:
                if getattr(action, 'directly_reaches_mop', False):
                    dm_actions.append(action)
                elif getattr(action, 'reaches_mop', False):
                    m_actions.append(action)
        
        suggestions = []
        
        if dm_actions:
            suggestions.append(f"Priority: Test [DM] actions first ({len(dm_actions)} available)")
        
        if m_actions:
            suggestions.append(f"Secondary: Explore [M] actions ({len(m_actions)} available)")
            
        if not dm_actions and not m_actions:
            suggestions.append("Explore systematically to discover monitored operations")
        
        return " | ".join(suggestions)
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy", 
        phase="violations_insight_building"
    )
    def _build_violations_insight(self, state: Dict[str, Any]) -> str:
        """
        Build contextual insights from recent monitored operations violations.
        
        Analyzes violation patterns to provide strategic guidance for continued
        exploration and pattern recognition.
        
        Args:
            state: Application state containing recent violation information
            
        Returns:
            Formatted violation insight analysis for prompt guidance
        """
        recent_errors = state.get(StateEntry.MOP_RECENT_ERRORS, [])
        if not recent_errors:
            return ("🔍 DISCOVERY MODE: No violations detected yet - "
                   "focus on [DM] actions for maximum potential")
        
        insights = ["## VIOLATION PATTERN ANALYSIS"]
        
        # Analyze recent violations for actionable patterns  
        violation_specs = {}
        for error in recent_errors[-3:]:  # Last 3 violations
            spec = error.get('spec', 'unknown')
            violation_specs[spec] = violation_specs.get(spec, 0) + 1
        
        if violation_specs:
            insights.append("Recent violations detected:")
            for spec, count in violation_specs.items():
                insights.append(f"• {spec}: {count}x")
            insights.append(
                "🎯 STRATEGY: Continue exploring similar interaction patterns for additional violations"
            )
        
        return "\n".join(insights)
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy",
        phase="navigation_context_building"
    )
    def _build_navigation_context(self, state: Dict[str, Any]) -> str:
        """
        Build navigation intelligence from static analysis data.
        
        Leverages Window Transition Graph (WTG) data to provide strategic
        navigation guidance for coverage expansion.
        
        Args:
            state: Application state containing static analysis data
            
        Returns:
            Formatted navigation intelligence for prompt guidance
        """
        static_data = state.get(StateEntry.STATIC_DATA)
        if not static_data or not static_data.wtg:
            return ""
        
        current_activity = state.get(StateEntry.ACTIVITY, "")
        if not current_activity:
            return ""
        
        nav_context = ["## NAVIGATION INTELLIGENCE"]
        
        # Analyze possible transitions from Window Transition Graph
        possible_transitions = []
        for transition in static_data.wtg.edges:
            if transition.source_window == current_activity:
                possible_transitions.append(transition.target_window)
        
        if possible_transitions:
            nav_context.extend([
                f"📍 FROM {current_activity}:",
                f"🔄 Can navigate to: {', '.join(possible_transitions[:4])}",
                "💡 TIP: Actions may trigger activity transitions for coverage expansion"
            ])
        
        return "\n".join(nav_context) if len(nav_context) > 1 else ""
    
    @ErrorHandler.handle_errors(
        component="MOPVisionStrategy",
        phase="iteration_history_enhancement"
    )
    def _enhance_iteration_history(self, state: Dict[str, Any]) -> str:
        """
        Enhance sliding window iteration history with monitored operations insights.
        
        Processes recent iterations to highlight monitored operations targeting
        success patterns and provide strategic guidance for continued exploration.
        
        Args:
            state: Application state containing recent iteration history
            
        Returns:
            Enhanced iteration history with monitored operations analysis
        """
        recent_iterations = state.get(StateEntry.RECENT_ITERATIONS, [])
        if not recent_iterations:
            return ""
        
        enhanced_history = ["## MONITORED OPERATIONS ENHANCED ITERATION HISTORY"]
        
        for i, iteration in enumerate(recent_iterations[-3:]):  # Last 3 iterations
            iteration_num = iteration.get('iteration_number', i + 1)
            
            # Extract monitored operations relevant information
            actions_executed = iteration.get('actions_executed', [])
            mop_actions_taken = []
            coverage_progress = iteration.get('coverage_progress', {})
            
            for action in actions_executed:
                action_text = action.get('action_text', '')
                if '[DM]' in action_text or '[M]' in action_text:
                    mop_actions_taken.append(action_text.split(' ')[0])  # Extract action type
            
            # Format iteration with monitored operations context
            enhanced_history.append(f"### Iteration {iteration_num}")
            
            if mop_actions_taken:
                enhanced_history.extend([
                    f"🎯 Monitored Operations Actions: {', '.join(mop_actions_taken)}",
                    "✅ POSITIVE: Monitored operations targeting successful"
                ])
            else:
                enhanced_history.append("⚪ Standard actions - no monitored operations targeting")
            
            method_coverage = coverage_progress.get('method_coverage', 0.0)
            enhanced_history.append(f"📊 Coverage: {method_coverage:.1f}% methods")
            
            # Screen context summary
            screen_summary = iteration.get('screen_description_summary', '')
            if screen_summary:
                enhanced_history.append(f"📱 Context: {screen_summary[:50]}...")
            
            enhanced_history.append("")  # Spacing between iterations
        
        enhanced_history.append("💡 PATTERN: Continue monitored operations targeting based on successful patterns above")
        return "\n".join(enhanced_history)
    
    def _is_form_element(self, action: ItemAction, item) -> bool:
        """Determine if action represents a form input element."""
        return ("SET_TEXT" in action.text or 
                "EditText" in str(item.view) or 
                "input" in action.text.lower())
    
    def _is_navigation_element(self, action: ItemAction) -> bool:
        """Determine if action represents a navigation element."""
        nav_keywords = ['menu', 'tab', 'button', 'nav']
        return any(keyword in action.text.lower() for keyword in nav_keywords)
    
    def _is_configuration_screen(self, screen_description: ScreenDescription) -> bool:
        """Determine if screen represents configuration or settings interface."""
        config_keywords = ['config', 'setting', 'preference', 'option']
        screen_text = str(screen_description).lower()
        return any(keyword in screen_text for keyword in config_keywords)
    
    def _is_submit_action(self, action: ItemAction) -> bool:
        """Determine if action represents a form submission element."""
        submit_keywords = ['submit', 'login', 'save', 'confirm', 'send', 'apply']
        return any(keyword in action.text.lower() for keyword in submit_keywords)
    
    def _is_dropdown_action(self, action: ItemAction, item) -> bool:
        """Determine if action represents a dropdown or spinner element."""
        return ("spinner" in str(item.view).lower() or 
                "dropdown" in action.text.lower())
    
    def _compute_screen_hash(self, state: Dict[str, Any]) -> str:
        """Compute hash for current screen state for caching purposes."""
        activity = state.get(StateEntry.ACTIVITY, "")
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        
        if screen_description and hasattr(screen_description, 'items'):
            item_count = len(screen_description.items)
            return f"{activity}_{item_count}_{hash(str(screen_description)[:100]) & 0xFFFF}"
        
        return f"{activity}_unknown"
    
    def _is_cache_valid(self) -> bool:
        """Check if context analysis cache is still valid."""
        import time
        cache_lifetime = MOP_STRATEGY_CONSTANTS.CACHE_LIFETIME_SECONDS
        return (time.time() - self._cache_timestamp) < cache_lifetime
    
    def _update_cache_timestamp(self) -> None:
        """Update cache timestamp after successful cache operation."""
        import time
        self._cache_timestamp = time.time()

## **Simple Implementation Summary**

### **What was simplified:**
1. **Removed complex screen pattern analysis** - just count M/DM actions
2. **Removed violations insight building** - use existing MOP_RECENT_ERRORS
3. **Removed navigation intelligence** - use basic exploration
4. **Removed iteration history enhancement** - use existing RICH context mode
5. **Removed all helper methods** for pattern detection
6. **Simplified template** to only include essential MOP guidance
7. **Simplified instructions** to focus on [DM] priority

### **What remains:**
- Basic M/DM action counting and guidance
- Simple action sequence suggestions
- Extends VisionStrategy for multimodal capability
- Uses existing context modes (STATELESS/RICH)
- Maintains template inheritance structure

This provides the essential MOP Strategy functionality without over-engineering.
