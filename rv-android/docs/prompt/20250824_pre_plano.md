## **Estratégia de Implementação: Minimal & Elegant**

### **Princípio Orientador:**
> **Reusar ao máximo, adicionar o mínimo necessário, manter elegância arquitetural**

### **Problemas Identificados:**
1. **Priorização Sem Contexto**: M/DM flags existem mas priorização simples ignora contexto de tela (forms, navigation, etc.)
2. **Histórico Não MOP-Aware**: Sliding window history não destaca ações MOP ou padrões de sucesso  
3. **Coverage Feedback Limitado**: EventBus recebe eventos MOP mas não influencia seleção inteligentemente
4. **Context Mode Subutilizado**: VisionStrategy tem context_mode mas não otimizado para MOP discovery

### **Solução: Context-Intelligent Testing + UI Coverage (5 Componentes):**
1. **MOPVisionStrategy** - extends VisionStrategy com context intelligence e MOP-enhanced history
2. **Template mop_vision.xml** - extends vision.xml com MOP context variables  
3. **UICoverageTracker** - systematic UI element coverage tracking (universal para todas strategies)
4. **CoverageGuidanceFragment** - universal coverage guidance para exploration sistemática
5. **Fragment enhancements** - context-aware behavior + coverage annotations

## **Sistema de Histórico MOP-Enhanced**

### **Context Mode: STATELESS**
- **Memory System**: MemoryManager + HistoryFragment
- **Storage**: ShortTermMemory (per activity) + LongTermMemory (per task)
- **Content**: MemoryAction, MemoryState com activity tracking
- **MOP Enhancement**: HistoryFragment detecta ações [M]/[DM] no histórico e destaca padrões de sucesso

### **Context Mode: RICH**
- **Memory System**: `_record_iteration()` com sliding window (últimas 3-5 iterações)
- **Compression**: Iterações antigas comprimidas, recent_iterations mantidas completas
- **Content**: iteration_number, actions_executed, coverage_progress, screen_description_summary
- **MOP Enhancement**: `_enhance_iteration_history()` analisa ações MOP executadas, coverage progression, identifica padrões de targeting bem-sucedido

### **Informações Incluídas no Histórico MOP:**
- **🎯 MOP Actions**: Quais ações [M]/[DM] foram executadas em cada iteração
- **📊 Coverage Progress**: Evolução de method_coverage e MOP method discovery  
- **✅ Success Patterns**: Identify which screen contexts led to successful MOP violations
- **📱 Screen Context**: Abbreviated screen descriptions para context correlation
- **💡 Pattern Learning**: Guidance baseado em successful patterns from history

## **UI Element Coverage Tracking System (Universal)**

### **Arquitetura do Sistema:**
O UI Coverage System implementa tracking sistemático de elementos testados pela LLM, fornecendo guidance para exploration comprehensive e balanceamento de tipos de ação. Sistema universal aplicável a todas strategies (single, batch, vision, mop_vision).

### **Componentes Principais:**

#### **1. UICoverageTracker**
**Responsabilidade**: Track elemento interactions, action type balancing, coordinate actions
**Integração**: LongTermMemory enhancement via composition pattern
**Storage**: In-memory durante task execution, extensível para persistence

#### **2. ElementInteraction Data Model**
```python
class ElementInteraction:
    """
    Tracks interaction history for individual ScreenItem elements.
    
    Maintains selection frequency, temporal patterns, and action type diversity
    to support systematic UI exploration and balanced testing strategies.
    """
    
    element_id: str              # Unique identifier within screen context
    selection_count: int         # Number of times LLM selected this element
    last_selected_time: float    # Timestamp of most recent selection
    action_types_used: Set[str]  # Types of actions executed (click, set_text, etc.)
    monitored_operations_flag: bool  # Element has [M] or [DM] annotations
    
    def is_undertested(self, threshold: int = 2) -> bool:
        """Determine if element requires additional testing coverage."""
        return self.selection_count < threshold
```

#### **3. Coverage Integration Points**
- **ActionService**: Records LLM selections → updates coverage data
- **UIElementsFragment**: Annotations with coverage status ([UNTESTED], [TESTED-Nx])
- **CoverageGuidanceFragment**: Universal guidance section for all strategies
- **Template System**: Coverage variables accessible in all templates

### **Benefícios Arquiteturais:**

#### **Systematic Exploration**
- **Element Coverage**: Visual annotations guide LLM toward untested elements
- **Balanced Testing**: Action type distribution metrics prevent bias toward specific interactions
- **Temporal Tracking**: Identifies stale elements requiring re-testing
- **Universal Application**: Functions across all testing strategies without modification

#### **Monitored Operations Enhancement**
- **MOP Element Priority**: Elements with [M]/[DM] flags receive coverage priority tracking
- **Violation Pattern Learning**: Correlates element interactions with successful monitored operations discovery
- **Context-Aware Guidance**: Combines coverage data with MOP targeting strategies

#### **Performance Optimization**
- **Lightweight Design**: Minimal memory footprint with efficient data structures
- **Non-Intrusive Integration**: Zero impact on existing strategy implementations
- **Configurable Thresholds**: Adjustable coverage criteria per testing scenario

```python
from rvandroid_tool.llm.prompt.strategies.vision_strategy import VisionStrategy
from rv_llm.llm.constants import StateEntry, ContextMode

class MOPVisionStrategy(VisionStrategy):
    """
    MOP-focused vision strategy with context-intelligent action sequencing.
    
    Extends VisionStrategy with MOP-specific intelligence while preserving all
    multimodal capabilities, context modes (STATELESS/RICH), and coordinate actions.
    """
    
    DEFAULT_TEMPLATE = "mop_vision"
    
    def __init__(self, name: str = "mop_vision", context_mode: str = ContextMode.STATELESS, **kwargs):
        """Initialize with same context_mode support as VisionStrategy"""
        super().__init__(name, context_mode=context_mode, **kwargs)
        self.logger.info(f"Initialized MOP Vision Strategy with context_mode: {context_mode}")
    
    def _build_template_variables(self, state: Dict[str, Any], 
                                 context: Dict[str, Any], 
                                 information: Dict[str, Any]) -> Dict[str, Any]:
        """Override to add MOP-specific variable building"""
        
        # Get base variables from VisionStrategy (includes all existing logic)
        variables = super()._build_template_variables(state, context, information)
        
        # Enhance with MOP-specific variables
        variables['mop_priorities'] = self._extract_mop_priorities(state)
        variables['mop_violations_context'] = self._build_violations_context(state)
        variables['mop_coverage_status'] = self._build_coverage_summary(state)
        
        return variables
    
    def _extract_mop_priorities(self, state: Dict[str, Any]) -> str:
        """Extract MOP priority information from structured screen"""
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if not screen_description:
            return ""
        
        # Count M/DM actions
        dm_count = 0
        m_count = 0
        dm_actions = []
        m_actions = []
        
        for item in screen_description.items:
            for action in item.actions:
                if action.directly_reaches_mop:
                    dm_count += 1
                    dm_actions.append(f"[{action.id}] {action.text}")
                elif action.reaches_mop:
                    m_count += 1
                    m_actions.append(f"[{action.id}] {action.text}")
        
        priority_summary = f"CRITICAL-DM Actions: {dm_count} | HIGH-M Actions: {m_count}"
        
        if dm_actions:
            priority_summary += f"\n🔴 CRITICAL-DM: {', '.join(dm_actions[:3])}"
        if m_actions:  
            priority_summary += f"\n🟡 HIGH-M: {', '.join(m_actions[:3])}"
            
        return priority_summary
    
    def _build_violations_context(self, state: Dict[str, Any]) -> str:
        """Build context about recent MOP violations"""
        recent_errors = state.get(StateEntry.MOP_RECENT_ERRORS, [])
        if not recent_errors:
            return "No recent violations - explore DM actions for discovery"
        
        context_lines = ["RECENT VIOLATIONS FOUND:"]
        for error in recent_errors[-2:]:  # Last 2 violations
            spec = error.get('spec', 'unknown')
            message = error.get('message', 'no details')
            context_lines.append(f"- {spec}: {message}")
        
        context_lines.append("Continue exploring similar interaction patterns!")
        return "\n".join(context_lines)
    
    def _build_coverage_summary(self, state: Dict[str, Any]) -> str:
        """Build concise coverage status"""
        metrics = state.get(StateEntry.COVERAGE_METRICS, {})
        mop_coverage = metrics.get('mop_method_coverage', 0.0)
        unique_errors = metrics.get('unique_errors', 0)
        
        if mop_coverage < 30.0:
            priority = "🔍 DISCOVERY PHASE - Focus on DM actions"
        elif mop_coverage < 70.0:
            priority = "🎯 EXPLORATION PHASE - Target uncovered methods"
        else:
            priority = "🧪 EDGE CASE PHASE - Test unusual scenarios"
            
        return f"MOP Coverage: {mop_coverage:.1f}% | Violations: {unique_errors} | {priority}"

    def _enhance_iteration_history(self, state: Dict[str, Any]) -> str:
        """Enhance iteration history with MOP-specific insights for context_mode=rich"""
        
        # This method enhances sliding window history from VisionStrategy
        recent_iterations = state.get(StateEntry.RECENT_ITERATIONS, [])
        if not recent_iterations:
            return ""
        
        enhanced_history = ["## MOP-ENHANCED ITERATION HISTORY"]
        
        for i, iteration in enumerate(recent_iterations[-3:]):  # Last 3 iterations
            iteration_num = iteration.get('iteration_number', i+1)
            
            # Extract MOP-relevant information from iteration
            actions_executed = iteration.get('actions_executed', [])
            mop_actions_taken = []
            coverage_progress = iteration.get('coverage_progress', {})
            
            for action in actions_executed:
                action_text = action.get('action_text', '')
                if '[DM]' in action_text or '[M]' in action_text:
                    mop_actions_taken.append(action_text.split(' ')[0])  # Just action type
            
            # Format iteration with MOP context
            enhanced_history.append(f"### Iteration {iteration_num}")
            
            if mop_actions_taken:
                enhanced_history.append(f"🎯 MOP Actions: {', '.join(mop_actions_taken)}")
                enhanced_history.append("✅ POSITIVE: MOP targeting successful")
            else:
                enhanced_history.append("⚪ Standard actions - no MOP targeting")
            
            method_cov = coverage_progress.get('method_coverage', 0.0)
            enhanced_history.append(f"📊 Coverage: {method_cov:.1f}% methods")
            
            # Screen context summary
            screen_summary = iteration.get('screen_description_summary', '')
            if screen_summary:
                enhanced_history.append(f"📱 Context: {screen_summary[:50]}...")
            
            enhanced_history.append("")  # Blank line between iterations
        
        enhanced_history.append("💡 PATTERN: Continue MOP targeting based on successful patterns above")
        return "\n".join(enhanced_history)
```

### **2.1 UICoverageTracker Core Implementation**
**Local**: `modules/rvandroid-tool/src/rvandroid_tool/core/memory/ui_coverage_tracker.py` (NOVO)

**Architectural Rationale**: Implements systematic UI element interaction tracking with action type balancing and coordinate action support. Designed for universal integration across all testing strategies through composition pattern with existing memory systems.

**Core Implementation:**

```python
"""
UI Coverage Tracking System for systematic element exploration.

This module provides comprehensive tracking of UI element interactions during
LLM-driven testing, supporting coverage-guided exploration and action balancing
across all testing strategies.
"""

import time
from collections import defaultdict
from typing import Dict, Set, List, Optional, Tuple, Any
from dataclasses import dataclass
from datetime import datetime

from rv_android_core.constants import UI_COVERAGE_CONSTANTS
from rv_android_core.util.error.error_handler import ErrorHandler
from rv_android_core.util.error.exceptions import TrackingError
from rv_android_core.util.logging.constants import CONTEXT_COMPONENT
from rv_android_core.util.logging.manager import LoggingManager
from rv_screen_parser.parser.screen.visitor.model import ItemAction, ScreenDescription


@dataclass
class ElementInteraction:
    """
    Tracks interaction history for individual ScreenItem elements.
    
    ### Architectural Role:
    Maintains comprehensive interaction metadata for UI elements to support
    systematic exploration patterns and balanced testing strategies across
    different testing methodologies.
    
    ### Design Patterns:
    - **Value Object**: Immutable interaction state with computed properties
    - **Data Transfer**: Clean interface between tracking and guidance systems
    - **Temporal Tracking**: Time-based interaction patterns for stale detection
    
    ### Integration Points:
    - UICoverageTracker for aggregate coverage analysis
    - CoverageGuidanceFragment for LLM decision support
    - ActionService for real-time interaction recording
    """
    
    element_id: str
    element_description: str
    selection_count: int = 0
    last_selected_time: Optional[float] = None
    action_types_used: Set[str] = None
    monitored_operations_flag: bool = False
    
    def __post_init__(self):
        if self.action_types_used is None:
            self.action_types_used = set()
    
    def record_selection(self, action_type: str) -> None:
        """
        Record a new interaction with this element.
        
        Args:
            action_type: Type of action executed (click, set_text, scroll, etc.)
        """
        self.selection_count += 1
        self.last_selected_time = time.time()
        self.action_types_used.add(action_type)
    
    def is_undertested(self, threshold: int = UI_COVERAGE_CONSTANTS.UNDERTESTED_THRESHOLD) -> bool:
        """
        Determine if element requires additional testing coverage.
        
        Args:
            threshold: Minimum interaction count for adequate coverage
            
        Returns:
            True if element needs additional testing
        """
        return self.selection_count < threshold
    
    def get_coverage_annotation(self) -> str:
        """
        Generate coverage status annotation for prompt display.
        
        Returns:
            Human-readable coverage status indicator
        """
        if self.selection_count == 0:
            return " [UNTESTED]"
        elif self.selection_count == 1:
            return " [TESTED-1x]"
        else:
            return f" [TESTED-{self.selection_count}x]"


class UICoverageTracker:
    """
    Comprehensive UI element coverage tracking system.
    
    ### Architectural Decisions:
    - **Universal Integration**: Compatible with all testing strategies without modification
    - **Composition Pattern**: Extends existing memory systems without inheritance complexity
    - **Event-Driven Updates**: Real-time tracking through ActionService integration
    - **Lightweight Storage**: In-memory data structures optimized for task execution scope
    
    ### Role in the System:
    - **Coverage Analysis**: Tracks interaction patterns across UI elements and screens
    - **Action Balancing**: Monitors action type distribution to prevent testing bias
    - **Coordinate Tracking**: Records custom coordinate actions for comprehensive analysis
    - **Guidance Generation**: Provides coverage-based recommendations for LLM strategies
    
    ### Performance Considerations:
    - **Memory Efficient**: Uses compact data structures with configurable cleanup thresholds
    - **Computation Optimized**: Cached coverage calculations with incremental updates
    - **Thread Safe**: Supports concurrent access from multiple testing components
    """
    
    def __init__(self):
        """
        Initialize comprehensive UI coverage tracking system.
        
        Sets up tracking data structures, logging infrastructure, and error handling
        for systematic UI element interaction monitoring.
        """
        # Initialize logging infrastructure
        logging_manager = LoggingManager.get_instance()
        self.logger = logging_manager.get_logger(
            "rvandroid_tool.core.memory.ui_coverage_tracker",
            {CONTEXT_COMPONENT: "UICoverageTracker"}
        )
        
        # Initialize error handling
        self.error_handler = ErrorHandler.get_instance()
        
        # Core tracking data structures
        self.screen_coverage: Dict[str, Dict[str, ElementInteraction]] = {}
        self.action_type_balance: Dict[str, int] = defaultdict(int)
        self.coordinate_actions: List[Dict[str, Any]] = []
        
        # Performance optimization caches
        self._coverage_cache: Dict[str, str] = {}
        self._cache_timestamp: float = 0
        
        self.logger.info("Initialized UI coverage tracking system")
    
    @ErrorHandler.handle_errors(
        component="UICoverageTracker",
        phase="selection_recording"
    )
    def record_selection(self, screen_hash: str, action: ItemAction) -> None:
        """
        Record LLM selection of a specific UI element action.
        
        Updates interaction tracking data and action type balance metrics
        to support systematic coverage analysis and exploration guidance.
        
        Args:
            screen_hash: Unique identifier for current screen state
            action: ItemAction selected by LLM for execution
            
        Raises:
            TrackingError: If action recording fails due to invalid data
        """
        try:
            # Initialize screen tracking if needed
            if screen_hash not in self.screen_coverage:
                self.screen_coverage[screen_hash] = {}
                self.logger.debug(f"Initialized coverage tracking for screen: {screen_hash}")
            
            # Generate unique element identifier
            element_id = self._generate_element_id(action)
            
            # Initialize or retrieve element interaction
            if element_id not in self.screen_coverage[screen_hash]:
                self.screen_coverage[screen_hash][element_id] = ElementInteraction(
                    element_id=element_id,
                    element_description=action.text[:50],  # Truncate for readability
                    monitored_operations_flag=(action.directly_reaches_mop or action.reaches_mop)
                )
                self.logger.debug(f"Created interaction tracking for element: {element_id}")
            
            # Record the interaction
            interaction = self.screen_coverage[screen_hash][element_id]
            interaction.record_selection(action.action_type)
            
            # Update global action type balance
            self.action_type_balance[action.action_type] += 1
            
            # Invalidate coverage cache
            self._invalidate_cache()
            
            self.logger.debug(
                f"Recorded selection: screen={screen_hash}, element={element_id}, "
                f"type={action.action_type}, count={interaction.selection_count}"
            )
            
        except Exception as e:
            raise TrackingError(f"Failed to record element selection: {e}") from e
    
    @ErrorHandler.handle_errors(
        component="UICoverageTracker", 
        phase="coordinate_recording"
    )
    def record_coordinate_action(self, coordinates: Tuple[int, int], description: str) -> None:
        """
        Record custom coordinate-based action execution.
        
        Tracks coordinate actions generated by LLM for comprehensive action
        type balancing and exploration pattern analysis.
        
        Args:
            coordinates: Target coordinates (x, y) for action execution
            description: Human-readable description of coordinate action
            
        Raises:
            TrackingError: If coordinate action recording fails
        """
        try:
            coordinate_entry = {
                'coordinates': coordinates,
                'description': description,
                'timestamp': time.time(),
                'datetime': datetime.now().isoformat()
            }
            
            self.coordinate_actions.append(coordinate_entry)
            self.action_type_balance[UI_COVERAGE_CONSTANTS.COORDINATE_ACTION_TYPE] += 1
            
            # Maintain coordinate action history within reasonable bounds
            max_coordinate_history = UI_COVERAGE_CONSTANTS.MAX_COORDINATE_HISTORY
            if len(self.coordinate_actions) > max_coordinate_history:
                self.coordinate_actions = self.coordinate_actions[-max_coordinate_history:]
            
            self._invalidate_cache()
            
            self.logger.debug(
                f"Recorded coordinate action: {coordinates} - {description}"
            )
            
        except Exception as e:
            raise TrackingError(f"Failed to record coordinate action: {e}") from e
    
    def get_coverage_annotation(self, screen_hash: str, action: ItemAction) -> str:
        """
        Generate coverage status annotation for UI element.
        
        Provides visual coverage indicators for prompt generation to guide
        LLM toward systematic element exploration patterns.
        
        Args:
            screen_hash: Current screen identifier
            action: ItemAction to generate annotation for
            
        Returns:
            Coverage annotation string for prompt inclusion
        """
        if screen_hash not in self.screen_coverage:
            return " [UNTESTED]"
        
        element_id = self._generate_element_id(action)
        interaction = self.screen_coverage[screen_hash].get(element_id)
        
        if interaction is None:
            return " [UNTESTED]"
        
        return interaction.get_coverage_annotation()
    
    def get_action_balance_guidance(self) -> str:
        """
        Generate action type balancing guidance for LLM decision making.
        
        Analyzes action type distribution to identify testing bias and provide
        recommendations for more balanced exploration strategies.
        
        Returns:
            Formatted guidance string for prompt inclusion
        """
        if not self.action_type_balance:
            return ""
        
        # Use cached result if available and recent
        cache_key = "action_balance_guidance"
        if self._is_cache_valid() and cache_key in self._coverage_cache:
            return self._coverage_cache[cache_key]
        
        total_actions = sum(self.action_type_balance.values())
        balance_components = []
        
        for action_type, count in sorted(self.action_type_balance.items()):
            percentage = (count / total_actions) * 100
            balance_components.append(f"{action_type}: {count} ({percentage:.1f}%)")
        
        guidance = "Action Balance: " + " | ".join(balance_components)
        
        # Cache the result
        self._coverage_cache[cache_key] = guidance
        self._cache_timestamp = time.time()
        
        return guidance
    
    def get_screen_coverage_stats(self, screen_hash: str) -> Dict[str, int]:
        """
        Calculate coverage statistics for specific screen.
        
        Args:
            screen_hash: Screen identifier for statistics calculation
            
        Returns:
            Dictionary containing coverage metrics and element counts
        """
        if screen_hash not in self.screen_coverage:
            return {'total_elements': 0, 'tested_elements': 0, 'untested_elements': 0}
        
        interactions = self.screen_coverage[screen_hash]
        tested_count = sum(1 for interaction in interactions.values() 
                          if interaction.selection_count > 0)
        
        return {
            'total_elements': len(interactions),
            'tested_elements': tested_count,
            'untested_elements': len(interactions) - tested_count
        }
    
    def _generate_element_id(self, action: ItemAction) -> str:
        """
        Generate unique identifier for UI element tracking.
        
        Creates consistent element identifiers based on action properties
        for reliable coverage tracking across test iterations.
        
        Args:
            action: ItemAction to generate identifier for
            
        Returns:
            Unique element identifier string
        """
        widget_id = action.widget_id or "unknown"
        return f"{action.id}_{widget_id}_{hash(action.text) & 0xFFFF}"
    
    def _invalidate_cache(self) -> None:
        """Invalidate coverage calculation cache after data updates."""
        self._coverage_cache.clear()
        self._cache_timestamp = 0
    
    def _is_cache_valid(self) -> bool:
        """
        Check if coverage calculation cache is still valid.
        
        Returns:
            True if cache can be used, False if recalculation needed
        """
        cache_lifetime = UI_COVERAGE_CONSTANTS.CACHE_LIFETIME_SECONDS
        return (time.time() - self._cache_timestamp) < cache_lifetime
```
