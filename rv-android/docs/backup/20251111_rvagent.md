## 🐛 BUG IDENTIFICADO: Text Input Fallback

### Descrição
A feature **Text Input Fallback** está criando ações com `action_type='UNKNOWN'` em vez de `action_type='TYPE_TEXT'`.

### Localização
**Arquivo**: `modules/rv-agent/src/rv_agent/strategies/base_strategy.py`
**Linhas**: 269-283

### Código Problemático
```python
# Método: _generate_text_input_actions()
def _generate_text_input_actions(
    self,
    unvisited_items: List[ItemAction]
) -> Optional[ItemAction]:
    """Generate random TYPE_TEXT actions for EditText elements."""

    # Filter EditText elements
    edit_texts = [
        item for item in unvisited_items
        if item.view and item.view.get('class', '').endswith('EditText')
    ]

    if not edit_texts:
        return None

    # Select random EditText (20% probability triggered before calling this)
    item = random.choice(edit_texts)
    target = self._extract_target_info(item)
    text = self._generate_random_text()

    # Create TYPE_TEXT ItemAction
    action_id = hash(target['signature']) & 0x7FFFFFFF

    text_action = ItemAction(
        id=action_id,
        text=f"TYPE_TEXT({text})",
        event=WidgetEventType.TEXT_CHANGE,
        target_view=item.view,
        coordinates=(target['center_x'], target['center_y'])
    )

    # ❌ PROBLEMA: ItemAction não tem campo 'action_type'
    # A ação é criada mas não tem action_type definido
    # Quando convertida para dict, fica como 'UNKNOWN'

    return text_action
```

### Evidência do Bug
```python
# Log de erro (10 ocorrências no teste)
2025-11-10 11:57:06,207 - WARNING - ❌ UNKNOWN ACTION TYPE: UNKNOWN
2025-11-10 11:57:06,207 - WARNING -    Original action received:
    {'action_type': 'UNKNOWN', 'x': 607, 'y': 135,
     'id': 52992912, 'text': 'TYPE_TEXT(test)'}
```

### Investigação Necessária

**IMPORTANTE**: O usuário levantou uma questão crucial:

> "temos que pensar que tem telas que possuem elementos dinamicos, que nao aparecem no dom, como jogos ... mas devemos investigar melhor isso para termos certeza"

#### Hipóteses para UNKNOWN:

1. **Bug no Text Input Fallback** (mais provável)
   - ItemAction sem action_type definido
   - Conversão para dict resulta em 'UNKNOWN'
   - Solução: Adicionar campo action_type ao criar ItemAction

2. **Elementos Dinâmicos** (a investigar)
   - Jogos com canvas/OpenGL não têm coordenadas no UIAutomator
   - Elementos renderizados fora do DOM Android
   - Componentes customizados sem metadados adequados

3. **Ambos os casos** (possível)
   - Bug gera alguns UNKNOWNs
   - Elementos dinâmicos geram outros
   - Precisamos distinguir entre os dois

#### Análise dos 10 casos UNKNOWN:
```
1. ar.rulosoft.mimanganu (iteration 4)  - x=607, y=135, text='TYPE_TEXT(test)'
2. au.com.wallaceit.reddinator (iter 13) - x=540, y=269, text='TYPE_TEXT(test123)'
3. au.com.wallaceit.reddinator (iter 14) - x=540, y=269, text='TYPE_TEXT(test123)'
4. byrne.utilities.hashpass (iter 7)     - x=540, y=319, text='TYPE_TEXT(test@example.com)'
5-10. [restantes com padrão similar]
```

**Padrão observado**: Todos têm formato `TYPE_TEXT(...)` → **Confirma que são do bug, não de elementos dinâmicos**

### Solução Proposta

#### Opção A: Adicionar action_type ao ItemAction (requer mudança no modelo)
```python
text_action = ItemAction(
    id=action_id,
    text=f"TYPE_TEXT({text})",
    event=WidgetEventType.TEXT_CHANGE,
    action_type="TYPE_TEXT",  # ✅ ADICIONAR
    target_view=item.view,
    coordinates=(target['center_x'], target['center_y'])
)
```

**PROBLEMA**: ItemAction é do `rv-screen-parser`, não tem campo `action_type`

#### Opção B: Retornar dicionário em vez de ItemAction (RECOMENDADO)
```python
def _generate_text_input_actions(
    self,
    unvisited_items: List[ItemAction]
) -> Optional[Dict[str, Any]]:  # ✅ Retorna dict
    """Generate random TYPE_TEXT actions for EditText elements."""

    # ... código de seleção ...

    # Retornar dict com action_type correto
    return {
        "action_type": "TYPE_TEXT",  # ✅ CORRETO
        "x": target['center_x'],
        "y": target['center_y'],
        "text": text,
        "signature": target['signature']
    }
```

#### Opção C: Converter após criação
```python
text_action = ItemAction(...)

# Converter para dict e adicionar action_type
action_dict = {
    "action_type": "TYPE_TEXT",  # ✅ ADICIONAR
    "x": text_action.coordinates[0],
    "y": text_action.coordinates[1],
    "text": text,
    "id": text_action.id
}
return action_dict
```
