- **Performance Atual**: ~6s tempo de geração (3.7s média, 6.3s pico)
- **Tokens Input**: ~1945 tokens por prompt
- **Benchmark Comparativo**: Modelos similares geram em 0.85-2.5s
- **Gap Identificado**: 5-7x mais lento que benchmarks com tokens similares

### 2. Mapeamento do Fluxo de Dados

### 3. Sistema de Notações Identificado

#### 3.1 Monitored Operations Markers (Existing)
- `[M]`: Monitored operations (indirect)
- `[DM]`: Direct monitored operations
- **Implementação**: `abstract_visitor.py:457-459` adiciona ao `action.text`

#### 3.2 UI Coverage Tracker Markers (Existing)  
- `[UNTESTED]`: Element nunca testado pelo LLM (highest priority)
- `[TESTED-1x]`: Testado uma vez, pode precisar mais exploração
- `[TESTED-Nx]`: Testado N vezes, prioridade moderada
- `[WELL-TESTED]`: Testado extensivamente (lowest priority)
- **Implementação**: `ui_coverage_tracker.py:246-253`

#### 3.3 Notação Formal Proposta
- `()`: Action IDs exclusivamente (`CLICK (3)`, `SET_TEXT (1)`)
- `[]`: Metadados (MOP + UI tracking + análise estática)
- `{}`: Valores e textos de componentes (`{MESSAGE DIGEST}`, `{password}`)

```
6. [TESTED-Nx] - Elements tested multiple times
7. [WELL-TESTED] - Extensively tested elements
```

## 🔧 Detalhes Técnicos de Implementação

### Correção Crítica: Sistema de Markers

#### Problema Identificado
O plano inicial propunha duplicar a lógica de markers MOP no UIElementsFragment, mas os visitors já fazem essa marcação:

```python
# EM abstract_visitor.py:457-459 (JÁ EXISTE)
if action.directly_reaches_mop:
    action.text += " [DM]"
elif action.reaches_mop:
    action.text += " [M]"
```

#### Solução Correta
UIElementsFragment deve apenas **adicionar** markers UI Coverage aos markers MOP existentes:

```python
def _add_ui_coverage_marker(self, action: ItemAction, element_id: str) -> None:
    """Add UI coverage marker to existing action.text (preserving MOP markers)."""
    ui_marker = self._get_ui_coverage_marker(element_id)
    if ui_marker:
        action.text += f" {ui_marker}"

# Resultado:
# Visitor gera: "CLICK (3) [M]"
# Fragment adiciona: "CLICK (3) [M] [UNTESTED]"
```

```python
def format_for_template(self) -> str:
    action_texts = [f"{action.text}" for action in self.actions]
    return f"[{self.timestamp.strftime('%H:%M:%S')}] Executed: {', '.join(action_texts)}"
    # Resulta em: "[12:34:56] Executed: CLICK (3), SET_TEXT (1)"

# OTIMIZADO (compact)
def format_for_template(self) -> str:
    action_texts = []
    for action in self.actions:
        # Extract text content from action if available
        component_text = getattr(action, 'component_text', '')
        if component_text:
            action_texts.append(f"{action.text} {{{component_text}}}")
        else:
            action_texts.append(action.text)
    return ', '.join(action_texts)
    # Resulta em: "CLICK (3) {MESSAGE DIGEST}, SET_TEXT (1) {password}"
```
