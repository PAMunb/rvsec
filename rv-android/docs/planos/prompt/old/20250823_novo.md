# Plano Detalhado: MOP-Guided Testing Framework

## **Objetivo Principal**
Desenvolver uma ferramenta que encontre **mais violações MOP** e tenha **maior cobertura** de métodos monitored que as ferramentas existentes (RVAndroid, RVDroid, Ape, Monkey), utilizando as propriedades JavaMOP existentes traduzidas de CrySL.

## **Análise do Framework Atual**

### **Arquitetura RV-Android Identificada**

#### **1. Domínios Principais (`rv-android-core`)**
- **`Method`**: Contém flags `reaches_mop` (M) e `directly_reaches_mop` (DM)
- **`Widget`**: UI elements com flags M/DM propagados da análise estática  
- **`ScreenDescription`**: Estrutura hierárquica de `ScreenItem` com `ItemAction`
- **`ItemAction`**: Ações executáveis com flags M/DM, coordenadas, e `callback_signature`
- **`StaticAnalysisData`**: Agregador de `Classes`, `Windows`, e `WindowTransitionGraph`
- **`MethodCoverageData`**: Tracking de métodos chamados com timestamps

#### **2. Sistema LLM (`rv-llm` + `rvandroid-tool`)**
- **`LanguageModel`**: Abstração para diferentes providers (Ollama, Claude, etc.)
- **`LLMMessage`**: Suporte multimodal com `LLMTextContent` e `LLMImageContent`
- **`RVAndroidPromptFramework`**: Framework de prompts com fragments e strategies
- **Fragments**: `UIElementsFragment`, `MonitoredOperationsFragment`, `HistoryFragment`, `TransitionGuidanceFragment`
- **Strategies**: `VisionStrategy`, `BatchStrategy`, `SingleStrategy`

#### **3. Pipeline de Execução Atual**
```
Static Analysis → StaticAnalysisData → ScreenDescription (com M/DM) →
StateEnricher → LLMActionService → PromptFramework → LLM → 
ResponseProcessor → ActionGenerator → DroidBot execution
```

#### **4. Cobertura (`rv-coverage`)**
- **`CoverageTracker`**: Monitora métodos chamados via logcat parsing
- **`MethodCoverageData`**: Registra chamadas com `register_call()` e timestamps
- **EventBus**: Publica eventos de cobertura em tempo real

#### **5. WTG Dinâmico**
- **`DynamicWTG`**: Constrói grafo de transições atividade→atividade runtime
- **`ActivityNode`**: Registra visitas e elementos testados por activity

## **Problemas Identificados no Sistema Atual**

### **1. Priorização Inadequada de Ações**
- LLM recebe `ScreenDescription` com ações que têm flags M/DM, mas **não há priorização explícita** dessas ações
- `UIElementsFragment` apenas converte `ScreenDescription` para string sem destacar importância MOP
- Prompt strategies não incorporam **weight/priority** baseado em M/DM

### **2. Falta de Feedback Loop MOP**
- `CoverageTracker` monitora métodos, mas **não informa ao LLM** quais métodos MOP já foram reached
- LLM não sabe **quais métodos MOP ainda precisam ser alcançados**
- Sem correlação entre violações encontradas e ajuste de estratégia

### **3. Navegação Não-Otimizada**
- `DynamicWTG` registra transições mas **não guia navegação** para activities com mais potencial MOP
- LLM não recebe informação sobre **qual activity** tem mais métodos DM unreached

### **4. Prompt Strategies Genéricas**
- `VisionStrategy` e `BatchStrategy` são genéricas para exploration
- Nenhuma strategy específica para **maximização de cobertura MOP**

```python
from rv_android_core.domain.coverage import MethodCoverageData
from rv_android_core.domain.static import StaticAnalysisData
from rv_android_core.event.bus import EventBus
from rv_coverage.analysis.coverage.tracker import CoverageTracker

class MOPCoverageTracker:
    """
    Tracker especializado para métodos MOP que complementa o CoverageTracker existente.
    """
    
    def __init__(self, static_data: StaticAnalysisData, event_bus: EventBus):
        self.static_data = static_data
        self.event_bus = event_bus
        
        # Extrai métodos MOP da análise estática
        self.dm_methods = self._extract_dm_methods()  # directly_reaches_mop
        self.m_methods = self._extract_m_methods()    # reaches_mop
        
        # Tracking state
        self.reached_dm_methods = set()
        self.reached_m_methods = set()
        self.coverage_history = []
        
        # Subscribe para eventos de cobertura do CoverageTracker existente
        self.event_bus.subscribe(
            "coverage.method_called", 
            self._on_method_called
        )
    
    def _extract_dm_methods(self) -> set:
        """Extrai métodos que directly_reaches_mop da análise estática"""
        dm_methods = set()
        for class_name, clazz in self.static_data.classes.classes.items():
            for method in clazz.methods:
                if method.directly_reaches_mop:
                    dm_methods.add(method.signature)
        return dm_methods
    
    def _extract_m_methods(self) -> set:
        """Extrai métodos que reaches_mop da análise estática"""
        m_methods = set()
        for class_name, clazz in self.static_data.classes.classes.items():
            for method in clazz.methods:
                if method.reaches_mop and not method.directly_reaches_mop:
                    m_methods.add(method.signature)
        return m_methods
    
    def _on_method_called(self, event_data: dict):
        """Handler para eventos de método chamado"""
        method_signature = event_data.get("method_signature")
        
        if method_signature in self.dm_methods:
            self.reached_dm_methods.add(method_signature)
            self._publish_dm_coverage_event(method_signature)
        elif method_signature in self.m_methods:
            self.reached_m_methods.add(method_signature)
            self._publish_m_coverage_event(method_signature)
    
    def get_coverage_gaps(self) -> dict:
        """Retorna gaps de cobertura MOP para guiar próximas ações"""
        unreached_dm = self.dm_methods - self.reached_dm_methods
        unreached_m = self.m_methods - self.reached_m_methods
        
        return {
            "unreached_dm_methods": list(unreached_dm),
            "unreached_m_methods": list(unreached_m),
            "dm_coverage_pct": len(self.reached_dm_methods) / len(self.dm_methods) * 100,
            "m_coverage_pct": len(self.reached_m_methods) / len(self.m_methods) * 100,
            "total_mop_coverage": (len(self.reached_dm_methods) + len(self.reached_m_methods)) / 
                                 (len(self.dm_methods) + len(self.m_methods)) * 100
        }
```

#### **2. Action Priority Calculator (`priority_calculator.py`)**

```python
from rv_screen_parser.parser.screen.visitor.model import ScreenDescription, ItemAction
from typing import List, Tuple

class ActionPriorityCalculator:
    """
    Calcula prioridades das ações baseado em potencial MOP e gaps de cobertura.
    """
    
    def __init__(self, mop_tracker: MOPCoverageTracker):
        self.mop_tracker = mop_tracker
    
    def prioritize_actions(self, screen_description: ScreenDescription) -> List[Tuple[ItemAction, float]]:
        """
        Ordena ações por prioridade MOP-based.
        
        Returns:
            Lista de (ItemAction, priority_weight) ordenada por prioridade decrescente
        """
        gaps = self.mop_tracker.get_coverage_gaps()
        prioritized_actions = []
        
        for item in screen_description.items:
            for action in item.actions:
                priority = self._calculate_action_priority(action, gaps)
                prioritized_actions.append((action, priority))
        
        # Ordena por prioridade (maior primeiro)
        return sorted(prioritized_actions, key=lambda x: x[1], reverse=True)
    
    def _calculate_action_priority(self, action: ItemAction, gaps: dict) -> float:
        """
        Calcula prioridade da ação baseada em:
        - directly_reaches_mop = peso 10.0
        - reaches_mop = peso 5.0  
        - callback_signature matching unreached methods = peso adicional
        - ação normal = peso 1.0
        """
        base_priority = 1.0
        
        # Prioridade alta para ações DM
        if action.directly_reaches_mop:
            base_priority = 10.0
        elif action.reaches_mop:
            base_priority = 5.0
            
        # Bonus se callback pode alcançar método MOP ainda não reached
        callback_bonus = 0.0
        if action.callback_signature:
            if action.callback_signature in gaps["unreached_dm_methods"]:
                callback_bonus = 5.0
            elif action.callback_signature in gaps["unreached_m_methods"]:
                callback_bonus = 2.0
        
        return base_priority + callback_bonus
```

#### **3. MOP-Focused Prompt Strategy (`mop_strategy.py`)**

```python
from rv_llm.llm.prompt.strategy.base_strategy import PromptStrategy
from rv_llm.llm.constants import PromptStrategyType
from typing import Dict, Any, List, Optional

class MOPFocusedStrategy(PromptStrategy):
    """
    Strategy de prompt otimizada para descoberta de violações MOP.
    """
    
    DEFAULT_TEMPLATE = "mop_focused"  # Template específico
    
    def __init__(self, mop_tracker: MOPCoverageTracker, 
                 priority_calculator: ActionPriorityCalculator, **kwargs):
        super().__init__("mop_focused", **kwargs)
        self.mop_tracker = mop_tracker
        self.priority_calculator = priority_calculator
    
    def _generate_prompt(self, state: Dict[str, Any], 
                        context: Optional[Dict[str, Any]] = None) -> List[Dict[str, str]]:
        """
        Gera prompt focado em MOP coverage com priorização explícita.
        """
        # Extrai screen description
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if not screen_description:
            return self._create_fallback_messages()
        
        # Calcula prioridades das ações
        prioritized_actions = self.priority_calculator.prioritize_actions(screen_description)
        
        # Obtém gaps de cobertura MOP
        coverage_gaps = self.mop_tracker.get_coverage_gaps()
        
        # Constrói contexto MOP para template
        mop_context = self._build_mop_context(prioritized_actions, coverage_gaps)
        
        # Usa information manager para coletar outros fragments
        fragments = self._collect_fragments(state, context)
        
        # Adiciona contexto MOP específico
        fragments['mop_guidance'] = mop_context
        
        # Renderiza template MOP-focused
        template_name = self.get_template_name(context) or self.DEFAULT_TEMPLATE
        messages = self.template_repository.render_template(template_name, fragments)
        
        return messages
    
    def _build_mop_context(self, prioritized_actions: List[Tuple], 
                          coverage_gaps: dict) -> str:
        """Constrói contexto específico MOP para o prompt"""
        
        # Top 5 ações de maior prioridade
        top_actions = prioritized_actions[:5]
        
        context = f"""
## MOP COVERAGE STATUS
- DM Coverage: {coverage_gaps['dm_coverage_pct']:.1f}%
- M Coverage: {coverage_gaps['m_coverage_pct']:.1f}%  
- Total MOP Coverage: {coverage_gaps['total_mop_coverage']:.1f}%

## HIGH PRIORITY ACTIONS (MOP-focused)
"""
        
        for i, (action, priority) in enumerate(top_actions, 1):
            priority_label = "🔴 CRITICAL" if priority >= 10 else "🟡 HIGH" if priority >= 5 else "⚪ NORMAL"
            mop_info = ""
            if action.directly_reaches_mop:
                mop_info = " [DIRECT MOP ACCESS]"
            elif action.reaches_mop:
                mop_info = " [INDIRECT MOP ACCESS]"
                
            context += f"[{action.id}] {priority_label} {action.text}{mop_info}\n"
        
        context += f"""
## TESTING GUIDANCE
- PRIORITIZE actions marked as CRITICAL or HIGH
- Focus on reaching unreached MOP methods: {len(coverage_gaps['unreached_dm_methods'])} DM + {len(coverage_gaps['unreached_m_methods'])} M remaining
- Target activities with high MOP method concentration
"""
        return context
```

```python
from rv_llm.llm.prompt.information.base_fragment import InformationFragment
from rv_llm.llm.constants import FragmentType
from typing import Dict, Any, Optional

class MOPCoverageFragment(InformationFragment):
    """Fragment que injeta informações de cobertura MOP no prompt"""
    
    def __init__(self, mop_tracker: MOPCoverageTracker, priority_calculator: ActionPriorityCalculator):
        super().__init__("mop_coverage", priority=600)  # Alta prioridade
        self.mop_tracker = mop_tracker
        self.priority_calculator = priority_calculator
    
    def generate(self, state: Dict[str, Any], context: Optional[Dict[str, Any]] = None) -> str:
        """Gera informação de cobertura MOP formatada"""
        gaps = self.mop_tracker.get_coverage_gaps()
        
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if screen_description:
            prioritized_actions = self.priority_calculator.prioritize_actions(screen_description)
            high_priority_count = sum(1 for _, priority in prioritized_actions if priority >= 5.0)
        else:
            high_priority_count = 0
        
        return f"""
Current MOP Coverage: {gaps['total_mop_coverage']:.1f}% 
- DM Methods: {gaps['dm_coverage_pct']:.1f}% ({len(gaps['unreached_dm_methods'])} remaining)
- M Methods: {gaps['m_coverage_pct']:.1f}% ({len(gaps['unreached_m_methods'])} remaining)

High-Priority Actions Available: {high_priority_count}
FOCUS: Target DM actions (direct MOP access) for maximum violation discovery!
"""
    
    def should_include(self, state: Dict[str, Any], context: Optional[Dict[str, Any]] = None) -> bool:
        return True  # Sempre incluir contexto MOP

class MOPActionPriorityFragment(InformationFragment):
    """Fragment que reordena ações por prioridade MOP"""
    
    def __init__(self, priority_calculator: ActionPriorityCalculator):
        super().__init__("mop_prioritized_actions", priority=550)
        self.priority_calculator = priority_calculator
    
    def generate(self, state: Dict[str, Any], context: Optional[Dict[str, Any]] = None) -> str:
        """Gera lista de ações reordenada por prioridade MOP"""
        screen_description = state.get(StateEntry.STRUCTURED_SCREEN)
        if not screen_description:
            return "No screen actions available."
        
        prioritized_actions = self.priority_calculator.prioritize_actions(screen_description)
        
        output = "## ACTIONS (MOP-Prioritized)\n"
        for action, priority in prioritized_actions:
            priority_emoji = "🔴" if priority >= 10 else "🟡" if priority >= 5 else "⚪"
            mop_tags = []
            if action.directly_reaches_mop:
                mop_tags.append("DM")
            if action.reaches_mop and not action.directly_reaches_mop:
                mop_tags.append("M")
            
            mop_info = f" [{'/'.join(mop_tags)}]" if mop_tags else ""
            output += f"[{action.id}] {priority_emoji} {action.text}{mop_info}\n"
        
        return output
```

#### **5. WTG Activity Optimizer (`wtg_optimizer.py`)**

```python
from rv_android_core.domain.dynamic_wtg import DynamicWTG, ActivityNode
from rv_android_core.domain.static import StaticAnalysisData
from typing import List, Dict, Tuple

class WTGActivityOptimizer:
    """
    Otimiza navegação entre activities baseado em potencial MOP.
    """
    
    def __init__(self, static_data: StaticAnalysisData, dynamic_wtg: DynamicWTG, 
                 mop_tracker: MOPCoverageTracker):
        self.static_data = static_data
        self.dynamic_wtg = dynamic_wtg
        self.mop_tracker = mop_tracker
        
        # Calcula potencial MOP por activity
        self.activity_mop_potential = self._calculate_activity_mop_potential()
    
    def _calculate_activity_mop_potential(self) -> Dict[str, Dict]:
        """
        Calcula potencial de métodos MOP por activity baseado na análise estática.
        """
        potential = {}
        
        for class_name, clazz in self.static_data.classes.classes.items():
            if clazz.is_activity:
                dm_count = sum(1 for method in clazz.methods if method.directly_reaches_mop)
                m_count = sum(1 for method in clazz.methods if method.reaches_mop and not method.directly_reaches_mop)
                
                potential[class_name] = {
                    "dm_methods": dm_count,
                    "m_methods": m_count,
                    "total_mop": dm_count + m_count,
                    "priority_score": dm_count * 10 + m_count * 5  # Peso DM vs M
                }
        
        return potential
    
    def suggest_next_activity(self, current_activity: str) -> List[str]:
        """
        Sugere próximas activities a visitar baseado em:
        1. Potencial MOP (DM > M)
        2. Activities ainda não visitadas ou pouco exploradas
        3. Acessibilidade via WTG
        """
        coverage_gaps = self.mop_tracker.get_coverage_gaps()
        
        # Activities acessíveis via WTG
        reachable_activities = self._get_reachable_activities(current_activity)
        
        # Calcula score para cada activity
        activity_scores = []
        for activity in reachable_activities:
            score = self._calculate_activity_score(activity, coverage_gaps)
            activity_scores.append((activity, score))
        
        # Ordena por score (maior primeiro)
        return [activity for activity, score in sorted(activity_scores, key=lambda x: x[1], reverse=True)]
    
    def _calculate_activity_score(self, activity: str, coverage_gaps: dict) -> float:
        """
        Calcula score da activity baseado em:
        - Potencial MOP
        - Métodos MOP ainda não reached
        - Frequência de visitas (menos visitadas = maior score)
        """
        base_score = self.activity_mop_potential.get(activity, {}).get("priority_score", 0)
        
        # Penalty por visitas frequentes (explora menos visitadas)
        activity_node = self.dynamic_wtg.get_activity_node(activity)
        visit_penalty = activity_node.visit_count * 0.5 if activity_node else 0
        
        # Bonus para activities com métodos MOP unreached
        unreached_bonus = self._calculate_unreached_bonus(activity, coverage_gaps)
        
        return base_score + unreached_bonus - visit_penalty
    
    def get_mop_navigation_guidance(self, current_activity: str) -> str:
        """
        Gera guidance textual para navegação focada em MOP.
        """
        suggested_activities = self.suggest_next_activity(current_activity)[:3]
        
        if not suggested_activities:
            return "Continue exploring current activity - no high-priority targets identified."
        
        guidance = "## MOP NAVIGATION GUIDANCE\n"
        for i, activity in enumerate(suggested_activities, 1):
            potential = self.activity_mop_potential.get(activity, {})
            guidance += f"{i}. {activity} - {potential.get('dm_methods', 0)} DM + {potential.get('m_methods', 0)} M methods\n"
        
        return guidance
```

#### **6. Tool Principal (`mop_guided_tool.py`)**

```python
from rv_tools.builtin.abstract_tool import AbstractTool
from rv_tools.util.tool_spec import ToolSpec
from typing import Dict, Any

class MOPGuidedTestingTool(AbstractTool):
    """
    Tool principal que integra otimização MOP com o framework RV-Android existente.
    """
    
    TOOL_SPEC = ToolSpec(
        name="mop-guided-testing",
        description="MOP-optimized LLM testing with smart action prioritization and coverage tracking",
        version="1.0.0"
    )
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.mop_tracker = None
        self.priority_calculator = None
        self.wtg_optimizer = None
        
    @classmethod 
    def get_variants(cls) -> Dict[str, Dict[str, Any]]:
        return {
            "mop_focused": {
                "llm_strategy": "mop_focused",
                "coverage_optimization": True,
                "wtg_navigation": True,
                "priority_weighting": {"dm": 10.0, "m": 5.0, "normal": 1.0}
            },
            "balanced": {
                "llm_strategy": "mop_focused", 
                "coverage_optimization": True,
                "wtg_navigation": False,
                "priority_weighting": {"dm": 5.0, "m": 3.0, "normal": 1.0}
            }
        }
    
    def execute(self, timeout: int, **kwargs) -> bool:
        """
        Executa testing session com otimização MOP.
        
        Integra componentes MOP com LLMActionService existente:
        1. Inicializa MOP trackers
        2. Registra MOP strategy no PromptFramework  
        3. Injeta MOP fragments
        4. Executa testing loop com feedback MOP
        """
        try:
            # 1. Inicializar componentes MOP
            self._initialize_mop_components()
            
            # 2. Integrar com RVAndroidPromptFramework existente
            self._integrate_with_prompt_framework()
            
            # 3. Executar testing loop otimizado
            return self._run_mop_optimized_testing_session(timeout)
            
        except Exception as e:
            self.logger.error(f"MOP-guided testing failed: {e}")
            return False
    
    def _initialize_mop_components(self):
        """Inicializa componentes específicos MOP"""
        # Integra com componentes existentes
        event_bus = EventBus.get_instance()
        
        self.mop_tracker = MOPCoverageTracker(self.static_data, event_bus)
        self.priority_calculator = ActionPriorityCalculator(self.mop_tracker)
        self.wtg_optimizer = WTGActivityOptimizer(
            self.static_data, self.dynamic_wtg, self.mop_tracker
        )
    
    def _integrate_with_prompt_framework(self):
        """Integra MOP components com framework de prompt existente"""
        from rvandroid_tool.llm.prompt.rvandroid_framework import RVAndroidPromptFramework
        from rv_llm.factories.component_factory import LLMComponentFactory
        
        # Registra MOP strategy
        LLMComponentFactory.register_strategy(
            "mop_focused", 
            lambda: MOPFocusedStrategy(self.mop_tracker, self.priority_calculator)
        )
        
        # Registra MOP fragments no information manager
        framework = RVAndroidPromptFramework.create(self.config.prompt_config)
        framework.information_manager.register_fragment(
            MOPCoverageFragment(self.mop_tracker, self.priority_calculator)
        )
        framework.information_manager.register_fragment(
            MOPActionPriorityFragment(self.priority_calculator)
        )
    
    def _run_mop_optimized_testing_session(self, timeout: int) -> bool:
        """
        Executa session de testing com otimização MOP, reutilizando
        LLMActionService e infrastructure existente.
        """
        # Utiliza LLMActionService existente com MOP strategy
        action_service = LLMActionService(
            static_data=self.static_data,
            tool_config=self.config
        )
        
        # Override strategy para usar MOP-focused
        action_service.strategy_type = "mop_focused"
        
        # Testing loop (similar ao RVAndroid existente)
        start_time = time.time()
        while time.time() - start_time < timeout:
            
            # 1. Captura estado atual (reutiliza infraestrutura)
            current_state = self._capture_current_state()
            
            # 2. Enriquece estado com contexto MOP
            current_state['mop_coverage_gaps'] = self.mop_tracker.get_coverage_gaps()
            current_state['mop_navigation_guidance'] = self.wtg_optimizer.get_mop_navigation_guidance(
                current_state.get('current_activity')
            )
            
            # 3. Gera ações via LLMActionService (usa MOP strategy)
            actions = action_service.generate_actions(current_state)
            
            # 4. Executa ação (reutiliza ActionExecutor existente)  
            if actions:
                result = self._execute_action(actions[0])
                
                # 5. Atualiza tracking MOP
                self._update_mop_tracking(actions[0], result)
                
                # 6. Verifica se atingiu target de cobertura
                if self._check_coverage_target():
                    self.logger.info("Target MOP coverage reached!")
                    break
            else:
                self.logger.warning("No actions generated, ending session")
                break
        
        return True
    
    def _update_mop_tracking(self, executed_action, result):
        """Atualiza tracking após execução da ação"""
        # Coverage é atualizada automaticamente via EventBus
        # pelo CoverageTracker existente
        
        # Atualiza WTG se houve transição de activity
        if result.get('activity_transition'):
            self.dynamic_wtg.record_transition(
                result['source_activity'],
```

## **Conclusão**

Esta proposta oferece **diferenciação arquitetural genuína** focada especificamente em **maximizar descoberta de violações MOP**. Ao contrário das ferramentas existentes que fazem exploration genérica, nossa abordagem:

- **Prioriza explicitamente** ações com potencial MOP (DM > M > normal)
- **Tracked cobertura MOP** em tempo real para feedback loop
- **Guia navegação** baseada em potencial MOP das activities  
- **Otimiza prompts** com contexto específico de coverage gaps

A implementação **reutiliza completamente** o ecossistema RV-Android existente, adicionando apenas os componentes de otimização MOP necessários. Isso garante compatibilidade total e desenvolvimento eficiente focado no objetivo principal: **encontrar mais violações MOP**.
