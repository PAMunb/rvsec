# Feature Acceptance Checklist

Complete at each checkpoint and before final approval.

---

## Checkpoint #1: Approach Selection

Before proceeding to detailed planning:

- [ ] Discovery report complete
- [ ] All approaches documented with pros/cons
- [ ] Recommendation provided
- [ ] User selected approach
- [ ] Open questions resolved

---

## Checkpoint #2: Plan Approval

Before writing any code:

- [ ] Implementation plan complete
- [ ] Steps ordered by dependencies
- [ ] Tests planned for each step
- [ ] Rollback strategy defined
- [ ] User approved plan

---

## Checkpoint #3: Final Approval

Before marking feature complete:

### Functionality

- [ ] All acceptance criteria met
- [ ] Feature works as described
- [ ] Edge cases handled
- [ ] Error handling in place

### Code Quality

- [ ] Code review passed
- [ ] No critical issues
- [ ] Warnings addressed or documented
- [ ] Follows existing patterns

### Testing

- [ ] All unit tests pass
- [ ] All integration tests pass
- [ ] Coverage target met
- [ ] No regressions

### Documentation

- [ ] Code comments where needed
- [ ] Docstrings complete
- [ ] CLAUDE.md updated (if architectural change)
